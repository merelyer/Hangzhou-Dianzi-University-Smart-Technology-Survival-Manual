## 复习顺序建议
第一轮按讲次通读，建立知识链：成像 -> 数字图像 -> 增强 -> 几何变换 -> 颜色 -> 分割 -> 形态学 -> 特征 -> 三维 -> 匹配。

第二轮重点攻公式和算法步骤：针孔模型、直方图均衡化、空间滤波、仿射矩阵、形态学开闭运算、区域矩、双目深度公式、SSD/SAD/NCC。

第三轮做自测题，并把不会的题回到原 PDF 对应章节复查。
