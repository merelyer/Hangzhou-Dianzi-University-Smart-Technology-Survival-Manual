# 第8讲 腐蚀和膨胀

## 复习定位
本讲是数学形态学基础，重点是集合观点下的腐蚀、膨胀、开运算、闭运算、击中-击不中变换和基本形态学算法。常考题型包括定义、性质、操作效果判断和结构元素选择。

## 一页总览
形态学用结构元素考察图像形状。二值图像中，前景可看作集合 A，结构元素为 B。

膨胀 A ⊕ B：扩大前景、连接间隙、填补小裂缝。

腐蚀 A ⊖ B：缩小前景、去除小物体、断开细连接。

开运算 A ○ B = (A ⊖ B) ⊕ B：先腐蚀后膨胀，去小亮点、断细连接、平滑轮廓。

闭运算 A ● B = (A ⊕ B) ⊖ B：先膨胀后腐蚀，填小孔、连小缝、平滑轮廓。

## 集合基础
二值图像中，前景像素集合记为 A。结构元素 B 是一个小形状，带有原点。形态学操作就是让 B 在图像上滑动，并根据 B 与 A 的关系决定输出。

结构元素的形状和大小非常关键。圆盘适合处理圆形目标，线形结构元素适合检测或连接特定方向线段，方形结构元素适合规则块状区域。

## 膨胀
直观理解：当结构元素 B 的原点移动到某位置，只要 B 与 A 有交集，该位置就属于膨胀结果。

作用：
1. 扩大前景区域。
2. 连接距离较近的断裂部分。
3. 填补小凹陷或小缝隙。
4. 增粗细线。

副作用是目标变大，邻近目标可能粘连。

## 腐蚀
直观理解：当结构元素 B 的原点移动到某位置，只有 B 完全包含于 A，该位置才保留为前景。

作用：
1. 缩小前景区域。
2. 去除小亮点和细小突出。
3. 断开细连接。
4. 分离粘连目标。

副作用是目标变小，细小目标可能完全消失。

## 对偶性
膨胀和腐蚀在补集与结构元素反射意义下互为对偶。直观上，对前景膨胀等价于对背景腐蚀的补操作。理解对偶性能帮助记忆开闭运算效果。

## 开运算
开运算先腐蚀后膨胀。腐蚀去掉小物体和细连接，随后的膨胀尽量恢复剩余目标大小。因此开运算主要用于：
1. 去除小亮噪声。
2. 分离细连接的物体。
3. 消除小突起。
4. 平滑边界。

开运算不能完全恢复被腐蚀掉的小结构。

## 闭运算
闭运算先膨胀后腐蚀。膨胀填补小孔和缝隙，随后的腐蚀尽量恢复整体大小。因此闭运算主要用于：
1. 填补小黑洞。
2. 连接窄断裂。
3. 弥合细沟。
4. 平滑边界。

闭运算可能让距离较近的目标连接。

## 形态学梯度与边界提取
边界提取常用：
Boundary(A) = A - (A ⊖ B)

形态学梯度可用膨胀结果减腐蚀结果：
Gradient(A) = (A ⊕ B) - (A ⊖ B)

它能突出目标边界。

## 击中-击不中变换
击中-击不中用于检测特定形状。它同时要求某些位置属于前景，某些位置属于背景，因此适合端点、角点、孤立点和特定结构检测。

可以理解为：一个结构元素匹配目标前景，另一个结构元素匹配背景约束。二者同时满足时检测成功。

## 灰度形态学
二值形态学可以扩展到灰度图。灰度膨胀取邻域最大倾向于增强亮区域，灰度腐蚀取邻域最小倾向于增强暗区域。灰度开闭运算可用于背景估计、亮暗细节提取和形状滤波。

## 结构元素选择
结构元素越大，处理效果越强，但越容易破坏目标。结构元素方向会影响方向性结构，例如水平线结构元素更容易连接水平断裂，对垂直结构效果较弱。

复习时要把结构元素当成“探针”：它能通过的地方保留，不能通过的地方被去除或改变。

## 易错点
开运算是先腐蚀后膨胀，闭运算是先膨胀后腐蚀。顺序不能反。

膨胀不是一定“变好”，腐蚀也不是一定“去噪”。它们都依赖前景定义和结构元素。

处理黑色目标时，要先明确前景是黑还是白。形态学通常默认白色为前景。

开运算去小亮点，闭运算填小黑洞。这个结论建立在白色为前景的前提下。

## 常考问答
### 1. 如何用形态学分离粘连目标？
可选择比连接处略大的结构元素做腐蚀或开运算，断开细连接，再根据需要膨胀恢复目标大小。

### 2. 如何填补目标内部小孔？
若目标为白色前景，可使用闭运算，或使用孔洞填充算法。

### 3. 结构元素为什么重要？
形态学操作按结构元素的形状和尺度处理图像。结构元素决定哪些结构被保留、删除、连接或填补。

### 第 20 页
**腐蚀**
腐蚀是一种形态学操作，用于缩小图像中的前景物体（通常为白色区域）。
**定义**：对于二值图像，结构元素B对图像A的腐蚀定义为：所有使得结构元素B完全包含在A中的像素
点构成的集合。数学表达式为：A  B = {z | (B)_z  A}
**效果**：
- 消除物体边界点
- 使物体边界向内收缩
- 可以去除小于结构元素的孤立噪声点
- 断开物体之间的细小连接
**应用**：
- 去除图像中的小颗粒噪声
- 分离粘连的物体
- 计算物体的边界（原图减去腐蚀后的图像）
- 作为开运算和闭运算的基础操作
**注意**：腐蚀的程度由结构元素的大小和形状决定。结构元素越大，腐蚀效果越明显。

开运算与闭运算的性质
(A  B)° = A°  B
开运算满足以下性质：
(i) A  B 是 A 的子集（子图像）。
(ii) 如果 C 是 D 的子集，则 C  B 是 D  B 的子集。
(iii) (A  B)  B = A  B（幂等性）
类似地，闭运算满足以下性质：
(i) A 是 A · B 的子集（子图像）。
(ii) 如果 C 是 D 的子集，则 C · B 是 D · B 的子集。
(iii) (A · B) · B = A · B（幂等性）

### 第 46 页
击中-击不中变换
形态学击中-击不中变换是形状检测的基本工具。
若B表示由X及其背景构成的集合，则B在A中的匹配（或匹配集）记为A@B，其定义为：
A@B = (A  X) ∩ [A  (W - X)]
令B = (B, B)，其中B = X，B = (W - X)，则：
A@B = (A  B) ∩ (A  B)
因此，集合A  B包含所有（原点）位置，在这些位置上B在A中找到匹配（"击中"），而A
B包含所有位置，在这些位置上B在A的补集中找到匹配。
这被称为形态学击中-击不中变换。

## 边界提取
### 定义
边界提取是指从图像中提取出物体或区域的轮廓（边界）的过程。边界通常定义为图像中灰度值发生剧烈
变化的位置，即边缘。
### 基本原理
边界提取基于图像梯度或边缘检测算子，如Sobel、Canny、Prewitt等。通过计算图像的一阶或二阶导数
，识别出灰度变化显著的点，并连接成连续边界。
### 常用方法
1. **梯度算子**：如Sobel算子、Prewitt算子，通过卷积核计算水平和垂直方向的梯度。
2. **Canny边缘检测**：多阶段算法，包括高斯平滑、梯度计算、非极大值抑制、双阈值检测。
3. **Laplacian算子**：基于二阶导数，对噪声敏感，常与高斯滤波结合使用（LoG）。
### 数学表达
- 梯度幅值：\( G = \sqrt{G_x^2 + G_y^2} \)
- 梯度方向：\( \theta = \arctan(G_y / G_x) \)

**纹理分割**
纹理分割是图像分割中的一个重要分支，其目标是将图像划分为具有不同纹理特征的区域。与基于颜色或
灰度的分割不同，纹理分割关注的是像素邻域内的空间排列和统计模式。
**1. 纹理特征提取**
纹理特征提取是纹理分割的核心步骤。常用的方法包括：
* **统计方法**：基于像素灰度值的统计分布。
* **灰度共生矩阵 (GLCM)**：通过计算图像中特定距离和方向上的像素对灰度值出现的频率，提取对比度
、相关性、能量、同质性等特征。
* **局部二值模式
(LBP)**：通过比较中心像素与其邻域像素的灰度值，生成二进制模式，并统计其直方图作为纹理描述符。
* **结构方法**：将纹理视为由基本纹理基元（texel）按一定规则排列而成。通过提取基元及其排列规则
来描述纹理。
* **频谱方法**：基于傅里叶变换或Gabor变换。
* **Gabor滤波器**：一组不同尺度和方向的带通滤波器，能够捕捉纹理的局部频率和方向信息。对图像
进行Gabor滤波后，提取每个像素处的响应幅度作为特征向量。
**2. 分割算法**
基于提取的纹理特征，可以采用多种分割算法：

* **基于聚类的分割**：
* **K-means聚类**：将每个像素的特征向量作为输入，通过迭代优化将像素分配到K个聚类中，每个聚类
对应一个纹理区域。
* **模糊C均值聚类 (FCM)**：允许像素以一定的隶属度属于多个类别，适用于纹理边界模糊的情况。
* **基于图论的分割**：
* **Normalized Cut**：将图像构建为图，节点为像素或超像素，边权重表示像素间纹理特征的相似度。
通过最小化归一化割准则，将图分割成若干子图，对应不同的纹理区域。
* **基于深度学习的分割**：
* **卷积神经网络 (CNN)**：如U-Net、DeepLab等，通过端到端学习，直接从图像中学习纹理特征并进
行像素级分类。CNN能够自动学习复杂的纹理模式，是目前最先进的方法。
**3. 评估指标**
常用的纹理分割评估指标包括：
* **准确率 (Accuracy)**：正确分类的像素占总像素的比例。
* **交并比 (IoU)**：预测区域与真实区域的交集与并集之比。
* **Dice系数**：衡量两个区域重叠程度的指标，与IoU类似但更敏感于小区域。
* **兰德指数 (Rand Index)**：衡量分割结果与真实分割之间一致性的指标。
**4. 应用**
纹理分割广泛应用于：
* **医学图像分析**：如组织病理学图像中的细胞核分割、MRI图像中的脑组织分割。
* **遥感图像分析**：如土地利用分类、植被覆盖检测。
* **工业检测**：如表面缺陷检测、材料分类。
* **计算机视觉**：如场景理解、图像检索。
**总结**
纹理分割通过提取局部纹理特征并应用适当的聚类或分类算法，将图像划分为具有不同纹理属性的区域。
从传统的统计方法到现代的深度学习方法，纹理分割技术不断发展，为各种应用提供了强大的工具。
