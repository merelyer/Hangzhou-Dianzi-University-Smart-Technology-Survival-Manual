# 第7讲 点、线和边缘检测

## 复习定位
本讲进入图像分割，重点是不连续性检测：点检测、线检测和边缘检测。需要掌握模板响应、阈值判定、梯度算子、二阶导数、边缘连接和 Canny 边缘检测思想。

## 一页总览
图像分割可以基于灰度不连续性，也可以基于灰度相似性。不连续性方法寻找突变位置，包括孤立点、线和边缘。

模板检测通式：
R = sum_i w_i z_i

其中 w_i 是模板权重，z_i 是邻域像素。若 |R| 或 R 超过阈值，则认为检测到目标结构。

## 点检测
孤立点可用中心权重大、周围权重负的模板检测。若响应超过阈值，表示中心像素与周围差异显著。

点检测适用于寻找小亮点、小暗点、孔洞、颗粒或局部异常。阈值太低会产生噪声误检，阈值太高会漏检弱点。

## 线检测
线检测使用方向模板，对水平、垂直、+45 度、-45 度等方向分别计算响应。哪个方向响应最大，就说明该方向线结构最可能存在。

线检测本质上是匹配局部灰度模式。模板越大，对噪声越稳，但定位越粗；模板越小，定位精细但容易受噪声影响。

## 边缘检测
边缘是图像强度发生显著变化的位置。理想边缘有阶跃边缘、斜坡边缘、屋顶边缘等。真实图像中边缘常被噪声、模糊和采样影响。

边缘检测通常包含：
1. 平滑去噪。
2. 计算导数或梯度。
3. 确定边缘强度和方向。
4. 阈值化或边缘连接。

## 一阶导数与梯度
梯度：
grad f = [G_x, G_y]^T

梯度幅值：
M = sqrt(G_x^2 + G_y^2)

常用近似：
M = |G_x| + |G_y|

梯度方向：
alpha = atan2(G_y, G_x)

梯度方向指向灰度增长最快方向，边缘方向与梯度方向垂直。

## 常用梯度算子
Roberts 算子使用 2 x 2 模板，简单但对噪声敏感。

Prewitt 算子使用 3 x 3 模板，能估计水平和垂直梯度。

Sobel 算子在中心行或列给更大权重，有一定平滑作用，实际应用较常见。

## 二阶导数与拉普拉斯
拉普拉斯算子：
Laplacian f = d2f/dx2 + d2f/dy2

二阶导数对灰度变化更敏感，可通过零交叉检测边缘。但它对噪声也更敏感，因此常先用高斯平滑，形成 LoG 思想。

## Canny 边缘检测
Canny 是经典多阶段算法：
1. 高斯滤波去噪。
2. 计算梯度幅值和方向。
3. 非极大值抑制，使边缘变细。
4. 双阈值检测，分强边缘和弱边缘。
5. 滞后连接，保留与强边缘相连的弱边缘。

Canny 的优点是检测效果好、边缘细、抗噪性较强；缺点是参数选择影响明显，计算量比简单算子大。

## 边缘连接
边缘检测后常出现断裂，需要根据相邻性、梯度方向和梯度幅值相似性进行连接。Hough 变换可把图像空间中的点映射到参数空间，用于检测直线、圆等全局形状。

## 阈值分割与区域方法
虽然本讲重点是不连续性，但课件也提到相似性分割。阈值分割根据灰度范围把像素分成目标和背景；区域生长从种子点开始合并相似邻域；区域分裂合并根据一致性准则拆分或合并区域。

## 易错点
边缘方向和梯度方向不是一回事。梯度方向垂直于边缘。

二阶导数更敏感，不代表更好；噪声也会被增强。

阈值选择决定点、线、边缘检测效果。模板响应只是候选，最终还要阈值或连接规则。

Canny 中非极大值抑制是为了细化边缘，双阈值是为了兼顾漏检和误检。

## 常考问答
### 1. Sobel 算子为什么比简单差分抗噪？
Sobel 使用 3 x 3 邻域，并对中心方向赋较大权重，相当于在求导时融合了邻域信息，具有一定平滑效果。

### 2. Canny 的双阈值有什么作用？
高阈值确定可靠强边缘，低阈值保留可能的弱边缘。只有与强边缘连通的弱边缘才保留，可减少噪声误检。

### 3. 为什么边缘检测前常要平滑？
导数会放大噪声，平滑可以减少噪声造成的虚假边缘。

将图像与LoG进行卷积等同于先将图像与高斯平滑函数h进行卷积，然后对结果计算拉普拉斯算子。

基于阈值的图像分割
图像阈值化在图像分割应用中占据核心地位。
T2
阈值化可视为一种涉及对函数T进行检验的操作，其形式为
T = T[x, y, p(x, y), f(x, y)]
其中p(x, y)表示该点的某种局部属性，例如邻域的平均灰度级。

### 第 46 页
阈值处理
T = T[x, y, p(x, y), f(x, y)]
阈值化图像 g(x, y) 定义为：
若 f(x, y) > T，则 g(x, y) = 1
若 f(x, y) ≤ T，则 g(x, y) = 0
> 当 T 仅依赖于 f(x, y) 时，该阈值称为全局阈值。
> 当 T 同时依赖于 f(x, y) 和 p(x, y) 时，该阈值称为局部阈值。
> 当 T 还依赖于空间坐标 x 和 y 时，称为动态阈值或自适应阈值。

### 第 49 页
## 基于阈值的图像分割
### 直方图与阈值分割原理
- 原始图像（Original）的灰度分布可通过直方图（Histogram）进行分析
- 直方图横轴表示灰度级（0-255），纵轴表示像素数量
- 典型直方图示例中，像素数量峰值出现在约100和200灰度级处
### 阈值分割基本概念
- 阈值分割（Thresholding）是最简单的图像分割方法之一
- 通过设定一个或多个灰度阈值，将图像像素分为不同类别
- 基本公式：对于阈值T，分割后的二值图像g(x,y)可表示为：
- g(x,y) = 1 若 f(x,y) > T
- g(x,y) = 0 若 f(x,y) ≤ T
### 直方图特征分析
- 直方图峰值位置反映图像中主要目标的灰度分布
- 谷底位置通常可作为最佳阈值选择区域
- 示例直方图中，灰度值约150处为两个主要峰值的谷底，适合作为分割阈值

### 第 50 页
### 基于阈值的图像分割
- **原始图像**：未经处理的输入图像。
- **阈值化图像**：通过设定阈值将图像分割为前景和背景后的结果。
- **阈值过低**：导致过多像素被归类为前景，分割结果包含大量噪声或无关区域。
- **阈值过高**：导致前景像素被遗漏，分割结果丢失目标区域。

## Otsu算法
> Otsu方法以Nobuyuki Otsu（大津展之）命名。
> 它用于自动执行基于直方图形状的图像阈值分割，或将灰度图像降级为二值图像。
> 该算法假设图像包含两类像素或双峰直方图（例如前景和背景），然后计算分离这两类的最优阈值，使

## Otsu分割法
### 基本概念
Otsu分割法是一种基于直方图的自适应阈值分割方法，通过最大化类间方差来确定最佳分割阈值。
### 算法原理
- 目标：寻找最佳阈值T，使得前景和背景的类间方差最大
- 类间方差公式：σ²_B = ωω(μ - μ)²
- ω, ω：前景和背景的像素比例
- μ, μ：前景和背景的平均灰度值

### 相似性度量
> 最简单的度量是欧氏距离（Euclidean distance）。
设 **z** 表示 RGB 空间中的任意一点，**z** 与 **a** 之间的欧氏距离由下式给出：
D(z, a) = ||z - a|| = [(z - a)^T (z - a)]^{1/2}
(6.7-1)
= [(z_R - a_R)^2 + (z_G - a_G)^2 + (z_B - a_B)^2]^{1/2}
如果 D 小于指定的阈值 D，则称 **z** 与 **a** 相似。满足 D(z, a) ≤ D 的点的轨迹是一个半径为 D
的实心球体。
> 欧氏距离的一个有用推广形式为：
D(z, a) = [(z - a)^T C^{-1} (z - a)]^{1/2}
其中 C 是待分割颜色样本的协方差矩阵（covariance matrix）。满足 D(z, a) ≤ D
的点的轨迹描述了一个实心的三维椭球体，其主轴指向数据最大散布的方向。
