# 第9讲 区域特征

## 复习定位
本讲关注特征提取，尤其是区域、颜色、轮廓和局部特征。重点掌握为什么要提取特征、好特征的性质、区域几何特征、矩特征、不变性和特征匹配思路。

## 一页总览
特征是由图像测量量计算出的可量化属性，用于检测、分类、识别、匹配或定位。好的特征应具有区分性、重复性、鲁棒性、效率和一定不变性。

常见特征：
区域特征：面积、周长、质心、外接矩形、圆形度、长宽比。

颜色特征：颜色直方图、颜色矩、主色。

轮廓特征：边界、链码、曲率、傅里叶描述子。

局部特征：角点、斑点、SIFT/SURF/ORB 等关键点及描述子。

## 为什么提取特征
原始图像数据量大、冗余多、对光照和噪声敏感。特征提取把图像转为更简洁、更稳定、更适合决策的表示。

在全景拼接中，先找局部特征点，再匹配对应点，最后估计几何变换。在目标识别中，特征帮助区分不同类别。在机器人定位中，稳定特征可作为环境地标。

## 好特征的性质
### 可重复性
同一物体或场景在不同视角、尺度、光照下仍能检测到相同或相近特征。

### 区分性
不同目标的特征应差异明显，避免大量误匹配。

### 鲁棒性
对噪声、压缩、模糊、亮度变化和小变形不敏感。

### 不变性
根据任务需要，特征可对平移、旋转、尺度或光照变化保持稳定。

### 计算效率
实际系统中要考虑实时性，不能只追求复杂描述。

## 区域几何特征
### 面积
二值区域中前景像素个数。面积可用于筛除小噪声或按大小分类。

### 周长
区域边界长度。周长计算受像素网格和边界提取方式影响。

### 质心
区域中心：
x_bar = (1/A) sum x
y_bar = (1/A) sum y

质心用于定位目标。

### 外接矩形与长宽比
最小/轴对齐外接矩形可估计目标位置、尺寸和方向。长宽比用于区分细长目标和近圆目标。

### 圆形度
常见定义：
C = 4 pi A / P^2

A 是面积，P 是周长。圆越接近 1，形状越接近圆。边界噪声会增加周长，使圆形度下降。

### 紧致度与矩形度
紧致度描述区域是否集中，矩形度可用区域面积与外接矩形面积之比表示。

## 矩特征
普通矩：
m_pq = sum_x sum_y x^p y^q f(x, y)

零阶矩 m_00 对应面积，一阶矩用于计算质心。

中心矩：
mu_pq = sum_x sum_y (x - x_bar)^p (y - y_bar)^q f(x, y)

中心矩具有平移不变性。归一化中心矩可进一步处理尺度影响。Hu 不变矩通过组合矩获得平移、尺度、旋转不变性，常用于形状识别。

## 颜色特征
颜色直方图统计颜色分布，具有一定平移和旋转不敏感性，但丢失空间布局。颜色矩用均值、方差、偏度描述颜色分布，维度低，适合检索和粗分类。

颜色特征对光照变化敏感，实际应用常配合白平衡、颜色空间转换或归一化处理。

## 轮廓特征
轮廓描述目标边界形状。链码用方向序列表示边界，傅里叶描述子把边界看成复数序列并进行频域表示，可用于形状匹配。

轮廓特征适合形状明显的物体，但对遮挡、边界破损和分割质量敏感。

## 局部特征与匹配
局部特征通常包含检测器和描述子。检测器负责找关键点，描述子负责描述关键点邻域。

匹配流程：
1. 在两幅图像中检测关键点。
2. 计算描述子。
3. 根据距离或相似度做初始匹配。
4. 用比值测试、交叉验证或 RANSAC 剔除误匹配。
5. 估计几何关系。

局部特征的优势是即使目标部分遮挡，也可能依靠可见局部完成匹配。

## 易错点
特征不是越多越好。冗余特征会增加计算量，并可能引入噪声。

颜色直方图不包含空间位置信息，两幅颜色分布相同但布局不同的图像可能直方图相同。

区域特征强依赖分割结果。分割错了，面积、周长、质心都会错。

不变性要与任务匹配。需要识别旋转物体时旋转不变有利；需要估计姿态时完全旋转不变可能丢掉有用信息。

## 常考问答
### 1. 为什么区域特征常用于工业检测？
工业目标通常背景受控、分割较稳定，区域面积、位置、形状和尺寸能直接对应合格判定和测量需求。

### 2. Hu 矩为什么常用于形状识别？
Hu 矩由归一化中心矩组合而来，具有平移、尺度和旋转不变性，适合比较形状。

### 3. 局部特征比全局特征有什么优势？
局部特征对遮挡和背景干扰更鲁棒，可在图像局部建立对应关系，适合拼接、定位和目标匹配。

### 第 24 页
## 图像矩
### 什么是矩？
图像矩是通过特定公式计算得到的数值。
对于M×N的数字图像f(x,y)，(p+q)阶二维矩定义为：
$$m_{pq} = \sum_{x=0}^{M-1}\sum_{y=0}^{N-1} x^p y^q f(x,y)$$
当矩被用来描述区域目标时，它们具有平移、旋转和尺度不变性。
对应的(p+q)阶中心矩定义为：
$$\mu_{pq} = \sum_{x=0}^{M-1}\sum_{y=0}^{N-1} (x - \bar{x})^p (y - \bar{y})^q f(x,y)$$
其中，
$$\bar{x} = \frac{m_{10}}{m_{00}}, \quad \bar{y} = \frac{m_{01}}{m_{00}}$$

### 第 41 页
## 主轴
**主轴** 是指穿过物体所能绘制的最长直线的 (x, y) 端点。
主轴端点 (x, y) 和 (x, y)
通过计算物体边界上所有边界像素点对之间的像素距离，并找出具有最大长度的那一对来获得。
主轴长度 = √[(x - x)² + (y - y)²]
该结果是物体长度的度量。

### 第 42 页
## 主轴角度
主轴角度是主轴与图像x轴之间的夹角：
主轴角度 = tan¹( (Y - Y) / (X - X) )
- 角度范围：0° 到 360°
- 该结果用于衡量物体的朝向

### 第 44 页
### 紧凑度
紧凑度定义为物体的面积与具有相同周长的圆的面积之比。
紧凑度公式：
\[
\text{compactness} = \frac{4\pi \cdot \text{area}}{(\text{perimeter})^2}
\]
- 使用圆作为参考，因为圆是形状最紧凑的物体。
- 该度量对于圆取最大值1。
- 正方形的紧凑度 = \(\pi / 4\)

### 第 48 页
### 圆形度或圆度
一种衡量圆度或圆形度（面积与周长比）的方法，可以排除局部不规则性，通过计算物体面积与具有相同
凸周长的圆的面积之比得到：
\[
\text{圆形度} = \frac{4\pi \cdot \text{面积}}{(\text{凸周长})^2}
\]
该统计量对于圆形物体等于1，对于偏离圆形的物体小于1，但它对不规则边界的敏感度相对较低。如果
\(X_1, \ldots, X_n\) 是边界列表，则周长由下式给出：
\text{周长} = \sum_{i=1}^{n} \|X_i - X_{i-1}\|

## 颜色特征

### 第 52 页
颜色矩
用于度量两幅图像之间的相似性。
中心颜色矩包括均值、标准差和偏度。
均值：
\[
\text{mean}_i = \frac{1}{m \cdot n} \sum_{j=1}^{m} \sum_{k=1}^{n} I(j, k, i)
\]
其中 \( i \) 表示 R、G、B 三个通道，\( I(j, k, i) \) 表示对应通道中大小为 \( m \times n \) 的像素强度。
标准差：
\text{std}_i = \sqrt{\frac{1}{m \cdot n} \sum_{j=1}^{m} \sum_{k=1}^{n} (I(j, k, i) - \text{mean}_i)^2}
偏度：
\text{skewness}_i = \frac{1}{m \cdot n} \sum_{j=1}^{m} \sum_{k=1}^{n} (I(j, k, i) - \text{mean}_i)^3

### LBP主要思想
以某一点与其邻域像素的相对灰度作为响应，正是这种相对机制使LBP算子对于单调的灰度变化具有不变
性。

单调的，因此LBP在光照不均的人脸识别应用中也取得了很好的效果。

计算图像梯度：
计算图像横坐标和纵坐标方向的梯度，并据此计算每个像素位置的梯度方向值；
求导操作不仅能够捕获轮廓、人影和一些纹理信息，还能进一步弱化光照的影响。
图像中像素点(x, y)的梯度为：
Gx(x, y) = H(x + 1, y) - H(x - 1, y)
Gy(x, y) = H(x, y + 1) - H(x, y - 1)
其中Gx(x, y)和Gy(x, y)分别表示输入图像中像素点(x, y)的水平方向梯度和垂直方向梯度。H(x,
y)表示像素值。再以此计算出梯度的大小和方向：
G(x, y) = √(Gx(x, y)² + Gy(x, y)²)

### Haar-like 特征
#### Haar-like 特征的计算 - 积分图
在工程中需要进行快速计算某个矩形内的像素值的和，这就需要引入积分图的概念。
积分图是一种能够描述全局信息的矩阵表示方法。积分图的构造方式是位置 (x, y) 处的值
ii(x, y) 是原图像 (x, y) 左上角方向所有像素的和：
ii(x, y) = ∑_{x' ≤ x, y' ≤ y} i(x', y')
积分图构建算法：
1. 用 s(x, y) 表示行方向的累加和，初始化 s(x, -1) = 0；
2. 用 ii(x, y) 表示积分图，初始化 ii(-1, y) = 0；
3. 逐行扫描图像，递归计算每个像素的 s(x, y) 和 ii(x, y)：
- s(x, y) = s(x, y-1) + i(x, y)
- ii(x, y) = ii(x-1, y) + s(x, y)
4. 扫描图像一遍，当到达图像右下角像素时，积分图像就构造好了。

3. 消除边缘响应
H的特征值与D的主曲率成比例。设α为最大量级的特征值，β为最小量级的特征值，则
Tr(H) = Dxx + Dyy = α + β

Tr(H)² / Det(H) = (α + β)² / (αβ) = (rβ + β)² / (rβ²) = (r + 1)² / r
看主曲率是否低于某个阈值T：
Tr(H)² / Det(H) < (T + 1)² / T
（论文中取T = 10）
如果上式成立，则剔除特征点，否则保留。

DAISY特征
传统的SIFT方法，使用了加权的梯度幅值。
DAISY算子使用的是高斯核卷积的方法来对梯度直方图进行加权。当待计算点平移或旋转时，由于高斯核
具有各向同性，对于图像的旋转，直方图的数值也会随之改变。在提取稠密特征时，结果体现到直方图上
只是bin的顺序的改变，因此不需要重复计算梯度直方图。而SIFT方法在提取稠密特征时需要反复计算梯
度直方图，耗时很长。
