# 第5讲 仿射变换

## 复习定位
本讲是图像几何处理的核心，服务于图像配准、全景拼接、目标定位和坐标变换。重点掌握齐次坐标、平移、旋转、缩放、剪切、仿射变换、投影变换、正向/反向映射和插值。

## 一页总览
几何变换改变像素位置，灰度变换改变像素值。几何变换通常分两步：
1. 坐标映射：确定输出像素来自输入图像的哪个位置。
2. 灰度插值：当映射位置不是整数像素时估计灰度。

二维仿射变换可写为：

[x', y', 1]^T =
[[a, b, t_x],
 [c, d, t_y],
 [0, 0, 1]]
[x, y, 1]^T

仿射变换保持直线和平行性，但一般不保持长度和角度。

## 齐次坐标
二维点 (x, y) 写成齐次坐标 (x, y, 1)。齐次坐标的好处是把平移、旋转、缩放、剪切统一写成矩阵乘法，便于多个变换连续相乘。

复合变换顺序很重要。若列向量右乘，先执行的变换矩阵靠右。例如先旋转 R 再平移 T，总变换是 T R。

## 基本几何变换
### 平移
x' = x + t_x

y' = y + t_y

齐次矩阵：
[[1, 0, t_x], [0, 1, t_y], [0, 0, 1]]

### 缩放
x' = s_x x

y' = s_y y

若 s_x = s_y 是等比例缩放，否则会改变形状比例。

### 旋转
绕原点逆时针旋转 theta：
x' = x cos theta - y sin theta

y' = x sin theta + y cos theta

绕任意点旋转要先把该点平移到原点，旋转后再平移回去。

### 剪切
剪切会让矩形变成平行四边形，保持平行线关系，但改变角度。

## 仿射变换性质
仿射变换可以由线性变换和平移组成。它保持：
1. 点的共线性。
2. 直线仍为直线。
3. 平行线仍平行。
4. 线段比例保持。

它通常不保持长度、面积和角度，除非是特殊仿射变换，如刚体变换或相似变换。

## 投影变换
投影变换也称单应变换，二维形式为 3 x 3 齐次矩阵：

[x', y', w']^T = H [x, y, 1]^T

实际坐标为 x'/w'、y'/w'。投影变换比仿射变换更一般，可以描述平面在不同视角下的透视变化。它保持直线，但不保持平行性。

全景拼接中，如果相机绕光心旋转或场景近似平面，图像之间常可用单应矩阵对齐。

## 图像扭曲
图像扭曲是把输入图像的像素重新排列到输出图像。常见有正向映射和反向映射。

正向映射把输入像素投到输出图像，可能产生空洞，因为输出图像某些位置没有像素落入。

反向映射对每个输出像素反查输入位置，再插值得到灰度，通常更常用，因为能避免空洞。

## 插值方法
### 最近邻插值
取最近整数像素，速度快，但容易产生锯齿和块状感。

### 双线性插值
用周围四个像素按距离加权平均，效果平滑，计算量适中，是常用选择。

### 双三次插值
使用更大邻域，结果更平滑，细节保持更好，但计算量更大，可能产生轻微振铃。

## 图像配准与全景拼接
典型流程：
1. 提取特征点。
2. 匹配不同图像中的对应点。
3. 估计变换模型，如仿射矩阵或单应矩阵。
4. 使用 RANSAC 剔除错误匹配。
5. 图像扭曲和融合。

平移模型只能处理简单平移；仿射模型可处理旋转、缩放、剪切；投影模型能处理透视变化。

## 易错点
仿射变换保持平行，投影变换不一定保持平行。

几何变换改变位置，不直接改变灰度；但插值会让灰度发生数值变化。

复合矩阵顺序不能随意交换。旋转后平移和平移后旋转结果不同。

绕图像中心旋转不能直接用原点旋转矩阵，必须加入平移到中心和移回的步骤。

## 常考问答
### 1. 为什么图像几何变换需要插值？
变换后的坐标通常不是整数像素位置，而数字图像只在离散网格上有灰度值，因此必须用邻域像素估计该位置灰度。

### 2. 仿射变换需要几对对应点估计？
二维仿射变换有 6 个自由度，每对点提供两个方程，因此至少需要 3 对不共线对应点。

### 3. 单应矩阵需要几对对应点估计？
单应矩阵有 8 个自由度，至少需要 4 对对应点，且点不能处于退化配置。

### 第 48 页
## 齐次坐标
**问题：两条平行线可以相交。**
在欧几里得空间（几何）中，同一平面上的两条平行线不能相交，或者说永远无法相遇。
然而在射影空间中，例如，侧图中远处的铁轨在远离视线时会变得越来越窄。最终：两条平行的铁轨在地
平线处相交，这是一个无穷远点。
欧几里得空间（或笛卡尔空间）很好地描述了我们的2D/3D几何，但它们不足以处理射影空间。
一个二维点的笛卡尔坐标可以表示为(x, y)。无穷远点将是(∞, ∞)，这在欧几里得空间中变得没有意义。

### 第 53 页
## 齐次坐标
**证明：两条平行线可以相交。**
考虑欧氏空间中的以下线性方程组：
Ax + By + C = 0
Ax + By + D = 0
由于 C ≠ D，上述方程无解。
如果 C = D，则两条直线重合（重叠）。
Ax + By + Cw = 0
Ax + By + Dw = 0
(x, y, 0) 由于 (C - D)w = 0，因此 w = 0。所以，两条平行线相交于 (x, y, 0)，即无穷远点。

## 基本二维变换的3×3矩阵
| 变换类型 | 矩阵表示 |
|---------|---------|
| 平移 (Translate) | $\begin{bmatrix} 1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1 \end{bmatrix}$ |
| 缩放 (Scale) | $\begin{bmatrix} s_x & 0 & 0 \\ 0 & s_y & 0 \\ 0 & 0 & 1 \end{bmatrix}$ |
| 旋转 (Rotate) | $\begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0
