# 第5讲 预训练词向量 复习文档

依据：第5讲 预训练词向量 2026(1).pptx；配套教材第2.1节、第5章、第6章

## 考点地图

- NLP 技术范式：专家系统、统计模型、深度学习、大规模预训练模型。
- 文本表示与词语表示的关系。
- One-hot、词袋、分布式表示、嵌入表示。
- 静态词向量：NNLM、Word2Vec、GloVe。
- Word2Vec：CBOW、Skip-gram、负采样。
- GloVe：全局共现矩阵、加权回归、隐式矩阵分解。
- 动态词向量：CoVe、ELMo；上下文相关表示。
- 静态与动态词向量比较。

## 一、NLP 范式变迁

- 小规模专家系统阶段依靠人工规则和专家知识。例如情感分析中规定出现“好”“喜欢”判为褒义，出现“不”进行倾向反转。
- 语料库统计模型阶段使用离散、高维、稀疏向量表示词，结合统计机器学习进行分类、标注和检索。
- 深度学习阶段把词表示为低维稠密向量，让模型自动学习语义、语法和任务相关特征。
- 大规模预训练模型阶段采用“预训练 + 精调”范式：先在海量无标注语料上学习通用表示，再在下游任务标注数据上精调。

## 二、文本表示问题

- 文本表示是把自然语言文本转换为计算机能够理解和处理的数字形式，通常是向量或向量序列。
- 词语表示是文本表示的基础单元，研究如何表示单个词；整文表示是把句子、段落或文档表示为向量，常基于词表示组合得到。
- 好的文本表示决定模型性能上限。它需要尽可能捕捉语义、语法、上下文、词序和领域信息。

## 三、传统词表示

- One-hot 为词表中每个词分配唯一索引，向量维度等于词表大小，只有对应位置为 1，其余为 0。
- One-hot 优点是简单、无歧义；缺点是高维稀疏，无法表示词语相似性，任意两个不同词的距离都类似，且无法处理未登录词。
- 词袋 BOW 把文本表示为词频向量，忽略词序和句法结构。它适合传统分类和检索，但表达能力有限。
- 分布语义假设：一个词的意义可以由它的上下文决定，常在相似上下文中出现的词往往语义相似。这是词向量的理论基础。
- 嵌入表示把词映射为低维稠密连续向量，使相似词在向量空间中距离更近。

## 四、静态词向量

- 静态词向量指一个词在训练完成后对应一个固定向量，不随上下文变化。Word2Vec 和 GloVe 是典型代表。
- 神经网络语言模型 NNLM 通过预测下一个词学习词向量。语言模型任务可从无标注文本自动构造训练样本，因此属于自监督学习。
- NNLM 相比 N-gram 能缓解数据稀疏，并用神经网络捕捉更丰富的上下文特征；但早期模型计算成本较高。

## 五、Word2Vec

- Word2Vec 是高效训练静态词向量的方法，核心思想是利用局部上下文共现信息进行自监督学习。
- CBOW 根据上下文词预测中心词。它训练速度快，对高频词效果好。输入是窗口内上下文词向量，输出是中心词概率。
- Skip-gram 根据中心词预测上下文词。它对低频词和语义细节通常更友好，但训练样本更多、成本更高。
- 完整 Softmax 需要对整个词表归一化，词表很大时计算昂贵。负采样把多分类问题转为二分类：让真实中心词-上下文对得分高，让随机采样的噪声词对得分低。
- 负采样优势是每次只更新少量正负样本，大幅降低计算量。答题时要强调它不是随便删词，而是用噪声对近似原目标。

## 六、GloVe

- GloVe 全称 Global Vectors for Word Representation，核心思想是先统计全局词-上下文共现矩阵，再学习低维词向量去回归共现信息。
- 与 Word2Vec 更强调局部窗口预测不同，GloVe 显式利用全局共现统计，因此兼具矩阵分解和词向量学习思想。
- GloVe 构建共现矩阵 M，其中 M(w,c) 表示词 w 与上下文 c 在窗口中的共现次数。距离越远的共现贡献可被赋予较小权重。
- 训练目标是让词向量点积加偏置接近 log 共现次数，并用加权损失降低低频噪声和超高频词的影响。
- 考试比较 Word2Vec 和 GloVe：Word2Vec 是预测式、局部上下文、负采样常见；GloVe 是计数式 + 回归式、全局共现、隐式矩阵分解。

## 七、动态词向量

- 静态词向量把一个词所有上下文信息压缩成一个向量，因此难以处理一词多义。例如“下场”在“亲自下场参加比赛”和“落得这样的下场”中含义不同。
- 动态词向量又称上下文相关词向量。一个词的向量由它当前所在上下文计算得到，因此同一个词在不同句子中可以有不同表示。
- 动态词向量仍满足分布语义假设，只是语义不是聚合到单个固定向量，而是在具体上下文中通过序列模型组合出来。
- CoVe 使用机器翻译的序列到序列编码器预训练动态表示。优点是有较强上下文编码能力；缺点是依赖双语平行语料，通用性受限。
- ELMo 使用双向语言模型学习动态词向量。它从左到右和从右到左分别建模上下文，再组合多层 LSTM 表示。

## 八、ELMo

- ELMo 全称 Embeddings from Language Models，是典型动态词向量模型。
- 输入表示层使用字符级表示和卷积组合，能缓解未登录词问题，提高对形态变化、拼写和新词的鲁棒性。
- 双向语言模型分别预测前向下一个词和后向上一个词，使每个位置同时获得左侧和右侧上下文信息。
- ELMo 的最终词向量不是只取最后一层，而是对不同层次表示进行加权组合。底层更偏词法和句法信息，高层更偏语义信息，下游任务可学习合适的组合权重。
- ELMo 特点：动态、上下文相关；双向；字符级输入鲁棒；层次化表示；可作为外部特征接入下游模型。

## 九、静态与动态词向量比较

- 静态词向量：一词一向量，训练和使用简单，推理效率高，适合资源有限或语义歧义不强的任务；缺点是不能根据上下文区分词义。
- 动态词向量：一词多向量，表示由上下文决定，能处理多义词和复杂语义；缺点是模型更大，训练和推理成本更高。
- 发展方向：One-hot 高维稀疏 -> Word2Vec/GloVe 低维稠密静态向量 -> ELMo 动态上下文向量 -> BERT/GPT 等深层 Transformer 预训练语言模型。

## 课后题答题要点

- 文本表示：自然语言到数字向量的桥梁，分为词表示和整文表示。
- Word2Vec：CBOW 用上下文预测中心词，Skip-gram 用中心词预测上下文，负采样降低 Softmax 成本。
- GloVe：用全局共现矩阵训练词向量，目标是回归 log 共现次数。
- ELMo：双向语言模型 + 字符级输入 + 多层表示加权，解决静态词向量不能消解一词多义的问题。

## 名词解释清单

- 文本表示：把自然语言文本转换成机器可处理数字形式的过程。
- One-hot：每个词对应一个高维稀疏向量，只有一维为 1。
- 分布语义假设：词的意义由其上下文决定。
- 词嵌入：低维稠密连续词向量表示。
- Word2Vec：基于局部上下文预测训练静态词向量的方法。
- GloVe：利用全局共现矩阵学习词向量的方法。
- ELMo：基于双向语言模型的动态词向量模型。

## 易混点

- 分布式表示不等于分布式计算。这里指语义分布在向量多个维度中。
- CBOW 和 Skip-gram 的预测方向相反：CBOW 上下文到中心词，Skip-gram 中心词到上下文。
- GloVe 不是只做 SVD，它用词向量回归共现矩阵，是计数和预测思想的结合。
- ELMo 属于动态词向量，但还不是 BERT 那种深层 Transformer 预训练语言模型。
