# 第6讲 预训练语言模型 复习文档

依据：配套教材第4.4节注意力模型 + 第7章预训练语言模型

## 考点地图

- 注意力机制、自注意力机制、Transformer。
- Transformer 解决的问题：位置、Q/K/V、深层关系、多头注意力。
- 预训练语言模型 PLM 的特点：大数据、大模型、大算力。
- 预训练 + 精调范式。
- GPT：自回归语言模型、单向 Transformer、下游任务输入改造。
- BERT：自编码语言模型、MLM、NSP、双向 Transformer 编码器。
- PLM 应用：特征抽取、模型精调；文本分类、序列标注、阅读理解、问答。
- GPT 与 BERT 比较。

## 一、从词向量到预训练语言模型

- 第5讲的静态词向量解决了 One-hot 高维稀疏和语义相似性问题，但一词一向量，难以处理一词多义。
- ELMo 等动态词向量把词表示变成上下文相关表示，但通常更多作为下游模型的外部特征，模型结构和任务适配能力仍有限。
- 以 GPT、BERT 为代表的预训练语言模型把“上下文表示学习”提升到深层 Transformer 架构，并形成“预训练 + 精调”的统一范式。
- 广义上，Word2Vec、GloVe、CoVe、ELMo 也可看作预训练模型；狭义上，课程第6讲所说预训练语言模型主要指基于深层 Transformer 的 GPT/BERT 类模型。

## 二、注意力机制

- 注意力机制的直观思想：在生成或表示某个位置时，不平均使用所有信息，而是根据相关性给不同输入分配不同权重。
- 在序列建模中，注意力能直接建立远距离位置之间的联系。相比 RNN 逐步传递信息，注意力缓解了长距离依赖中的信息衰减。
- 一般计算流程：用当前查询 query 与各个键 key 计算相关性分数；对分数做 softmax 得到权重；用权重对值 value 加权求和，得到新的表示。
- 可记为 Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V。sqrt(d_k) 用于缩放点积，避免维度较大时 softmax 过于尖锐。

## 三、自注意力机制

- 自注意力 self-attention 指 Q、K、V 都来自同一个输入序列。它为序列中每个词重新计算一个融合上下文的新表示。
- 对于句子中任意两个词，自注意力可以直接计算相关性，因此适合捕捉长距离依赖。
- 原始自注意力存在几个问题：不包含位置信息；同一个输入向量同时承担查询、键、值三种角色；单层只直接建模两两关系；单个注意力头难以同时关注多种关系。

## 四、Transformer

- Transformer 是以自注意力为核心的序列建模架构。它通过位置编码、Q/K/V 映射、多层堆叠、前馈网络、残差连接、层归一化和多头注意力解决原始自注意力的问题。
- 位置编码或位置嵌入用于补充词序信息。否则“我喜欢你”和“你喜欢我”包含相同词集合，模型可能无法区分顺序差异。
- Q/K/V 映射把输入向量投影为 Query、Key、Value 三种角色，使模型分别学习“拿什么去查询”“被什么匹配”“贡献什么内容”。
- 多头注意力让模型在多个子空间中并行关注不同关系。例如某个头关注主谓关系，另一个头关注指代或邻近词。
- 前馈网络为每个位置引入非线性变换；残差连接和层归一化帮助深层模型训练稳定；多层堆叠可以建模更复杂、更高阶的组合关系。
- Transformer 优点是并行能力强、长距离依赖建模好、表示能力强；缺点是参数量大，注意力计算对序列长度通常呈平方复杂度，对数据和算力要求高。

## 五、预训练语言模型概述

- 预训练语言模型 Pre-trained Language Model 是先在大规模文本上学习通用语言表示，再迁移到具体下游任务的模型。
- “预训练 + 精调”可以类比通识学习和专业学习：预训练阶段从海量文本中学习词法、句法、语义、知识和常见模式；精调阶段用目标任务数据适配具体任务。
- 三大特点：大数据、大模型、大算力。大数据提供丰富上下文，大模型提供足够容量，大算力支撑训练过程。
- 预训练数据既要保量也要保质。规模越大越能覆盖不同语境，但低质量语料会引入噪声，因此通常需要去重、清洗、过滤和分词。
- 大模型通常使用深层 Transformer。参数量大带来强表示能力，也带来训练成本、推理成本和过拟合风险。

## 六、GPT：自回归预训练语言模型

- GPT 是以自回归语言模型为核心的预训练语言模型。自回归指根据左侧历史上下文预测下一个词。
- 训练目标可写为最大化 P(w1, ..., wn) = product_t P(w_t | w_1, ..., w_{t-1})。模型只能看当前位置左侧信息，因此天然适合文本生成。
- GPT 使用多层 Transformer 解码器结构，配合因果掩码，保证模型预测当前位置时不能看到未来词。
- 应用下游任务时，GPT 倾向把任务改写为统一的文本序列输入输出形式。例如分类任务可把文本和候选标签拼成序列，让模型评估或生成答案。
- GPT 优点是生成能力强、任务形式统一；局限是单向上下文使其在需要完整双向理解的任务上不如 BERT 式编码器自然。

## 七、BERT：自编码预训练语言模型

- BERT 是基于深层 Transformer 编码器的预训练语言模型，核心优势是双向上下文表示。
- BERT 的输入表示通常由 Token Embedding、Segment Embedding、Position Embedding 相加得到。特殊符号 [CLS] 常用于整句或句对分类，[SEP] 用于分隔句子。
- 掩码语言模型 MLM：随机遮盖输入中的部分 token，让模型根据左右双向上下文预测被遮盖词。它使模型能同时利用左、右上下文学习表示。
- 下一句预测 NSP：给定两个句子，判断第二句是否为第一句的真实后续。它旨在帮助模型学习句间关系。后续模型对 NSP 是否必要有不同改进，但课程基础中应掌握其原始作用。
- BERT 适合理解类任务，如文本分类、序列标注、自然语言推断、阅读理解、抽取式问答。
- BERT 局限：MLM 预训练与精调输入不完全一致；不天然适合从左到右长文本生成；模型参数量大，训练和部署成本高。

## 八、应用方式

- 特征抽取：冻结预训练模型，把输出向量作为下游模型特征。优点是训练成本低、避免大规模更新；缺点是预训练模型不能充分适配目标任务。
- 模型精调：在预训练模型顶部加任务层，并用下游标注数据更新模型参数。优点是效果通常更好，能利用模型大容量学习任务知识；缺点是计算和存储成本更高，数据少时可能过拟合。
- 文本分类：通常取 [CLS] 表示接分类层。
- 序列标注：对每个 token 的输出向量接标签分类器，如 NER、POS。
- 阅读理解或抽取式问答：预测答案片段的起始位置和结束位置。
- 句对任务：把两段文本用 [SEP] 拼接，并用 Segment Embedding 区分句子。

## 九、GPT 与 BERT 比较

- 模型目标：GPT 是自回归，预测下一个词；BERT 是自编码，预测被 mask 的词并学习句间关系。
- 上下文方向：GPT 单向从左到右；BERT 双向编码。
- 结构：GPT 使用 Transformer 解码器思想和因果掩码；BERT 使用 Transformer 编码器。
- 擅长任务：GPT 更适合生成；BERT 更适合理解、分类、标注和抽取式问答。
- 共同点：都依赖大规模无标注文本预训练，都使用 Transformer，都可通过精调迁移到下游任务。

## 可能简答题模板

- 什么是 Transformer：以自注意力为核心，通过位置编码、多头注意力、前馈网络、残差连接和层归一化构成的序列建模架构。
- 为什么 Transformer 适合 PLM：并行计算效率高，能建模长距离依赖，参数容量大，适合从海量文本中学习通用表示。
- 什么是预训练 + 精调：先用大规模无标注语料学习通用语言表示，再用下游任务标注数据更新模型以适配任务。
- BERT 为什么是双向：MLM 让模型根据被遮盖词左右两侧上下文进行预测，Transformer 编码器允许每个位置关注双向上下文。
- GPT 与 BERT 比较：从训练目标、上下文方向、模型结构、适用任务四方面写。

## 考前速记

- 注意力 = 相关性打分 + softmax 权重 + value 加权求和。
- Transformer 四件套：位置编码、Q/K/V、多头注意力、前馈网络。
- PLM 三大特点：大数据、大模型、大算力。
- GPT：自回归、单向、擅长生成。
- BERT：MLM + NSP、双向、擅长理解。
- 应用方式：特征抽取和模型精调；考试重点通常是精调。

## 名词解释清单

- 注意力机制：按相关性给输入信息分配权重并加权求和的机制。
- 自注意力：同一序列内部各位置之间相互计算注意力。
- 多头注意力：并行使用多组注意力，在不同子空间捕捉不同关系。
- Transformer：以自注意力为核心的深层序列建模架构。
- 预训练语言模型：在大规模文本上预先训练、可迁移到下游任务的语言模型。
- 自回归语言模型：根据历史上下文预测下一个词的模型。
- 掩码语言模型：遮盖部分词并根据上下文预测被遮盖词的模型。

## 易混点

- 注意力机制不是只用于翻译，Transformer、BERT、GPT 都以注意力为核心。
- 自注意力本身不包含词序，必须通过位置编码或位置嵌入加入顺序信息。
- GPT 和 BERT 都是预训练语言模型，但训练目标和上下文方向不同。
- 特征抽取通常冻结预训练模型；精调会更新预训练模型参数。
