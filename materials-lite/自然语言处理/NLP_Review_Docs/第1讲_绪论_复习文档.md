# 第1讲 绪论 复习文档

依据：第1讲 绪论 2026.pptx

## 考点地图

- 自然语言、人工语言、自然语言处理的定义。
- NLP 的核心任务：理解、转换、生成。
- NLP 与人工智能、机器学习、计算语言学、自然语言理解之间的关系。
- NLP 研究内容的层次：应用层、应用基础层、基础层。
- 自然语言处理的主要困难：歧义、未知语言现象、语言开放演化。
- 主要研究方法：理性主义方法与经验主义方法。
- 技术发展脉络：规则系统、统计学习、深度学习、预训练大模型。

## 一、自然语言与人工语言

- 自然语言是随着社会发展自然产生、不断发展演化、用于人类日常交流与思考的符号系统。它的核心特点是自然产生、持续演化、表达灵活、依赖上下文。
- 人工语言是为特定目的设计的语言，如 SQL、Python 等。它们通常规则明确、语义单一、系统性强、适合结构化处理。
- 自然语言难处理的根本原因在于：规则不能完全覆盖所有现象，词汇和表达不断变化，同一句话在不同语境下可能有不同解释。
- 汉语相对英语的特殊性包括：词语边界不显式，需要自动分词；缺少形态变化，时态、数、格等信息往往通过语境表达；语序、虚词、省略和话题结构对理解影响大。

## 二、自然语言处理的定义与目标

- 自然语言处理是让计算机模拟人类对自然语言进行智能化处理的技术。它既包含语言工程和应用系统实现，也依赖语言学、统计学习、机器学习、深度学习和大规模计算。
- 理解：识别文本的结构、意义、情感、意图、指代和隐含知识。例如情感分析、阅读理解、语义角色标注。
- 转换：把一种语言形式转换为另一种形式。例如机器翻译、摘要、信息抽取、文本结构化。
- 生成：根据任务条件生成自然、连贯、符合语境的文本。例如对话系统、自动写作、问答生成。
- 课程中可把 NLP 看成从词、句、篇逐步建立表示和理解的技术体系：词法分析提供词级基础，句法分析提供结构基础，语义分析提供意义基础，预训练模型提供统一表示能力，检索和问答体现应用落地。

## 三、相关概念辨析

- 人工智能是研究让机器表现出智能行为的总领域；机器学习是当前实现人工智能的重要方法；自然语言处理是人工智能中面向语言智能的核心分支。
- 计算语言学偏向用计算机研究语言现象与规律，研究目标更偏科学解释；自然语言处理更强调应用系统、工程实现和任务效果。
- 自然语言理解偏向语言认知与理解机理，通常更强调语义、知识和推理；自然语言处理范围更宽，既包括理解，也包括转换和生成。

## 四、研究内容分层

- 应用层研究：面向最终用户问题，包括机器翻译、信息检索、问答系统、文本分类、情感分析、自动摘要、对话系统、信息抽取等。
- 应用基础层研究：支撑应用层的基础任务，包括词法分析、句法分析、语义分析、篇章分析、语言模型、文本表示等。
- 基础层研究：提供资源和理论支撑，包括语料库、词典、语言知识库、规则库、标注规范、评测数据集等。
- 考试作答时可按“层次名称 + 代表任务 + 作用”三步写，避免只列名词。

## 五、主要困难

- 歧义是最核心困难。同一语言形式可能有多种切分、词性、句法结构、词义或指代解释。
- 分词歧义例：乒乓球拍卖完了，可以切为“乒乓球拍/卖/完/了”，也可以切为“乒乓球/拍卖/完/了”。
- 词性和词义歧义例：“研究”可作名词或动词；bank 可表示银行或河岸。
- 句法歧义例：“我看见了拿望远镜的人”中，“拿望远镜”可能修饰“我看见”的方式，也可能修饰“人”。
- 指代歧义例：“小王告诉小李，他通过了考试”中的“他”可能指小王，也可能指小李。
- 未知语言现象包括新词、专名、网络语、缩写、错别字、口语化表达和领域术语。词典和训练语料无法穷尽所有表达。

## 六、研究方法

- 理性主义方法依靠语言学知识、人工规则和专家知识。优点是可解释性强、可控性强、适合规则明确场景；缺点是覆盖率低、规则维护成本高、难以处理开放语言现象。
- 经验主义方法依靠语料、统计规律和机器学习。优点是能从数据中自动学习模式，覆盖面广，适合复杂任务；缺点是依赖数据规模与质量，可解释性较弱，可能受训练分布限制。
- 现代 NLP 通常是经验主义为主、语言知识为辅。预训练模型利用海量无标注文本学习通用语言表示，再通过精调适配具体任务。

## 课后题答题要点

- 什么是 NLP：写出“让计算机模拟人类对自然语言进行理解、转换、生成”的定义，再说明它是人工智能的重要分支。
- 研究内容划分：应用层、应用基础层、基础层，每层至少举 3 个例子。
- 主要困难：必须写歧义和未知语言现象，并给出例子。答题时分层写更完整：词法、句法、语义、篇章。
- 基本方法：理性主义和经验主义。比较时从知识来源、优点、缺点、适用场景四方面展开。

## 考前速记

- NLP = 自然语言对象 + 计算机处理 + 智能化目标。
- 三大目标：理解、转换、生成。
- 三层内容：应用层、应用基础层、基础层。
- 两大困难：歧义、未知语言现象。
- 两类方法：理性主义靠规则，经验主义靠数据。

## 名词解释清单

- 自然语言：随社会发展自然产生并演化、供人类日常交流和思考使用的符号系统。
- 人工语言：为特定目的人工设计的语言，规则明确、语义稳定，如 SQL、Python。
- 自然语言处理：让计算机模拟人类对自然语言进行智能化处理的技术。
- 计算语言学：使用计算方法研究语言现象和语言规律的学科，偏理论与机理。
- 自然语言理解：关注机器对语言意义、意图和知识的理解，是 NLP 的重要方向。

## 易混点

- NLP 不是机器学习的同义词。机器学习是方法，NLP 是任务领域；NLP 可以使用规则、统计、深度学习和预训练模型。
- 计算语言学更偏语言规律研究，NLP 更偏技术系统和应用效果。
- 自然语言的难点不仅是语法复杂，更重要的是歧义、上下文依赖、开放词汇和世界知识。
