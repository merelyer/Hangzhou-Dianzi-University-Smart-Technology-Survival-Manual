## 一、句法分析概述

- 句法分析是在句子层面进行的形式化分析，核心目标是确定句子的句法结构或句子中词语之间的依存关系。
- 特点：分析对象是完整句子；关注形式和语法结构，而不是直接进行深层语义理解；结果服务于语义角色标注、信息抽取、机器翻译、问答等任务。
- 主要任务包括句法结构分析、浅层句法分析和依存句法分析。句法结构分析又常称完全句法分析。

## 二、句法结构分析

- 句法结构分析 syntactic structure parsing 是对输入单词序列判断其是否合乎给定语法规则，并确定符合语法规则的句法结构。
- 输出通常是句法分析树 syntactic parsing tree。树中非终结符表示短语类别，终结符表示句中词语。
- 典型短语标记：S 句子，NP 名词短语，VP 动词短语，PP 介词短语，ADJP 形容词短语，ADVP 副词短语。
- 分析器需要两类知识：词典提供词到词类的映射；语法规则库提供短语组成规则，如 S -> NP VP，VP -> V NP。
- 人工规则方法优点是原理简单、可解释；缺点是规则覆盖有限、主观性强、工作量大、难以选择最优树。
- 统计方法从树库中学习规则和概率，能降低人工编制成本，并在多棵候选树中选择概率更高的结构。

## 三、CFG 与 CNF

- 上下文无关文法 CFG 可表示为四元组 G = (V, T, P, S)。V 是非终结符集合，T 是终结符集合，P 是产生式规则集合，S 是开始符号。
- CFG 推导过程从开始符号 S 出发，反复用规则替换非终结符，直到得到终结符序列。
- 乔姆斯基范式 CNF 要求规则只有两类形式：A -> B C 或 A -> a。其中 A、B、C 是非终结符，a 是终结符。CYK 算法通常要求文法先转为 CNF。
- 把普通 CFG 转成 CNF 的基本方向：消除空产生式、消除单产生式、替换长右部、把终结符从混合右部中单独提出。

## 四、CYK 算法

- CYK 是基于动态规划的自底向上句法分析算法，用于判断句子是否能由 CNF 文法生成，并可恢复句法分析树。
- 表格含义：table[i, j] 表示从第 i 个词开始、长度为 j 的片段可以归约成哪些非终结符。
- 初始化：对每个词 wi，查找所有 A -> wi 的规则，把 A 填入长度为 1 的单元格。
- 递推：按跨度从短到长枚举片段，对每个切分点把左片段符号 B 和右片段符号 C 组合，若存在规则 A -> B C，则把 A 填入当前格。
- 终止：若覆盖整句的顶层单元包含 S，则句子可由该文法生成。若保存回溯指针，则可恢复一棵或多棵句法树。
- 考试做 CYK 题时要画三角表、按跨度填写、保留多种可能，不要只写最终答案。

## 五、PCFG

- 概率上下文无关文法 PCFG 是给 CFG 中每条产生式附加概率的模型。同一左部非终结符展开成不同右部的规则概率之和通常为 1。
- 一棵句法树的概率等于树中所有产生式概率的乘积。最优句法树就是在所有候选树中概率最大的树。
- PCFG 的优势：既能描述语法合法性，又能处理结构歧义；参数可从树库统计估计；可与 CYK/Viterbi 结合求最大概率树。
- PCFG 的局限：基本 PCFG 假设规则展开只依赖左部非终结符，忽略丰富上下文；可能无法充分刻画词汇、父节点、兄弟节点等信息。因此有词汇化 PCFG、父节点注释等改进方法。

## 六、浅层句法分析

- 浅层句法分析 chunking 不输出完整句法树，只识别句子中的局部短语块，如基本名词短语 Base NP、动词短语片段等。
- Base NP 通常指不包含其他 NP 的最小名词短语。它对信息抽取、术语识别、问答候选定位很有用。
- 浅层分析优点是难度低、鲁棒性强、适合工程应用；缺点是无法提供完整层次结构，也不能完整解释全句句法关系。

## 七、依存句法分析

- 依存句法分析直接刻画词与词之间的支配或修饰关系。通常每条依存边连接一个中心词 head 和一个依存词 dependent，并带有关系标签。
- 常见关系：SBV 主谓关系，VOB 动宾关系，IOB 间宾关系，FOB 前置宾语，DBL 兼语，ATT 定中关系，ADV 状中关系，CMP 动补关系，COO 并列关系，POB 介宾关系，LAD 左附加，RAD 右附加，DE 与“的”字结构相关。
- 依存结构相比短语结构更直接反映词间关系，适合语义角色标注、信息抽取和机器翻译。
- 基于转移的方法把分析过程看作一系列移进、归约、加边等动作，速度快、适合在线解码；基于图的方法把所有可能依存边组成图，寻找得分最高的依存树，通常全局性更强。

## 三类句法分析比较

- 句法结构分析：输出完整短语结构树，强调层次和组成关系。
- 浅层句法分析：只识别局部语块，强调实用和鲁棒。
- 依存句法分析：输出词与词之间的依存边，强调中心词和支配关系。
- 答题时可从输出形式、分析深度、优点、应用场景四方面比较。

## 课后题答题要点

- 术语：S 是句子，VP 是动词短语，NP 是名词短语，PP 是介词短语；SBV 主谓，VOB 动宾，ATT 定中，DE 与“的”字结构相关。
- PCFG 特点：CFG + 概率；树概率为规则概率乘积；能从树库学习；可选择最大概率树。
- CYK 题：先转 CNF，再填对角线，然后按跨度递推，最后看顶格是否含 S，并回溯结构树。

## 名词解释清单

- 句法分析：确定句子句法结构或词间依存关系的形式化分析。
- 句法分析树：用树结构表示句子的层次化句法组成。
- CFG：由非终结符、终结符、产生式和开始符号组成的上下文无关文法。
- CNF：规则形如 A -> B C 或 A -> a 的乔姆斯基范式。
- CYK：基于动态规划的 CFG 句法分析算法。
- PCFG：为 CFG 产生式附加概率的概率文法。
- 依存关系：词与词之间的支配、修饰或论元关系。

## 易混点

- CFG 判断句子是否合语法，PCFG 还能给不同句法树排序。
- CYK 的表格单元表示某个连续片段能归约成哪些非终结符，不是直接填词性序列。
- 浅层句法分析不输出完整树，只识别局部语块。
- 短语结构强调组成层次，依存结构强调词与词之间的中心-依存关系。
