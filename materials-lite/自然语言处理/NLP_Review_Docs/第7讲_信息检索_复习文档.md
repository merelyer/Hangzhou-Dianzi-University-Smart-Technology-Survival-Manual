## 一、信息检索概述

- 信息检索 Information Retrieval，简称 IR，是从大规模非结构化数据集合中找出满足用户信息需求的资料的过程，文本检索是最典型场景。
- 形式化描述：给定文档库 D 和用户查询 query，系统返回与查询相关的有序文档列表 [d1, d2, ...]。
- 产生背景包括信息过载、用户需求提升和用户群体下沉。搜索引擎、情报跟踪、内容安全、舆情分析都依赖 IR 技术。
- 好的检索系统要避免三类问题：返回内容不相关；真正需要的内容排在很靠后；靠前结果雷同、缺少多样性。

## 二、信息检索系统一般框架

- 文档表达：把文档库中的每篇文档转换为统一数学表示，称为标引 Indexing。
- 查询表达：把用户查询也转换成与文档同空间的表示。
- 相关度评估 Relevance Measuring：计算查询表达与候选文档表达的相关程度。
- 文档排序 Relevance Sorting：按相关度、重要性等指标排序，返回 top N 文档。
- 基于 VSM 的三个关键点：如何表达文档和查询，如何计算相关度，如何排序返回。

## 三、VSM 实现流程

- 文本预处理：中文分词、词性标注、虚词过滤。课件示例中强调可去除动词、名词、副词、形容词之外的其他词，实际系统会按任务选择保留词类。
- 特征选择：从词项集合中选择代表文档内容的特征。基于频率的方法可按词项在文档库中出现频次排序，选择阈值以上词项。
- 计算特征权重：常用 TF-IDF。词在当前文档中越频繁越重要，但出现在大量文档中的通用词区分度低，应降低权重。
- 编码成向量：把每篇文档表示为词项权重向量，把查询也表示为同维向量。
- 相似度评估：常用余弦相似度。夹角越小，余弦值越接近 1，表示文档与查询越相似。
- 排序返回：按相似度降序排序，返回 top N 个文档。课件提到冒泡排序只是示意，真实系统常用更高效排序和索引结构。

## 四、TF-IDF 与余弦相似度

- TF Term Frequency 表示词项在文档中的出现频率。它体现词项对当前文档的重要性。
- IDF Inverse Document Frequency 表示逆文档频率。若一个词出现在许多文档中，它区分文档的能力弱，IDF 应较低。
- 常见形式：tf-idf(t,d) = tf(t,d) * log(N / df(t))，其中 N 是文档总数，df(t) 是包含词 t 的文档数。不同教材可能有平滑变体。
- 余弦相似度：cos(x,y) = (x · y) / (||x|| ||y||)。它关注向量方向，能降低文档长度差异的影响。
- 考试计算题要写清词表维度、文档向量、查询向量、点积、模长和最终余弦值。

## 五、信息检索基本模型

- 布尔模型：用 AND、OR、NOT 等逻辑表达式匹配文档。优点是简单、精确、可解释；缺点是不自然排序，难表达相关度强弱。
- 向量空间模型 VSM：把文档和查询表示为向量，用相似度排序。优点是可排序、实现简单；缺点是词项独立假设强，难处理同义词和多义词。
- 语言模型：把每篇文档看作能生成查询的语言模型，计算查询由文档生成的概率。优点是概率解释清晰；缺点是需要平滑和参数选择。
- 概率模型：估计文档与查询相关的概率，并按相关概率排序。BM25 可视为经典概率检索思想的重要工程化模型。

## 六、LSI 隐性语义标引

- LSI Latent Semantic Indexing 使用 SVD 对词-文档矩阵进行降维，把文档和词项映射到低维隐语义空间。
- 基本动机：传统 VSM 基于表层词项，无法很好处理同义词和多义词。例如“计算机”和“电脑”表层不同，但语义接近；多义词可能干扰检索。
- 构建词-文档矩阵 C：行对应词项，列对应文档，元素通常是词频或 TF-IDF 权重。
- 进行奇异值分解：C = U Sigma V^T。U 表示词项到隐语义维度的关系；Sigma 是奇异值对角矩阵，表示各语义维度的重要程度；V^T 表示文档在隐语义维度上的表示；C 是原始词-文档矩阵。
- 降维：只保留最大的 k 个奇异值及对应维度，得到低秩近似 C_k = U_k Sigma_k V_k^T。这样可以去噪，并把同义词关联到相近语义维度。
- 检索时，查询也要投影到同一隐语义空间，再与文档隐语义向量计算相似度。

## 七、LSI 优势与局限

- 优势一：缓解同义词问题。即使文档 d1 包含“计算机”、d2 包含“电脑”，在语义空间中二者可能仍接近。
- 优势二：降低多义词噪声。多义词与多个语义维度相关，经过降维后其对某一具体语义维度的干扰可能被削弱。
- 优势三：降维与降噪。保留主要语义维度，去掉低重要度维度中的噪声。
- 局限：SVD 计算成本高；新增文档更新不方便；低维语义维度不易解释；线性模型表达能力有限；对参数 k 敏感。

## 八、信息检索系统评测

- 准确率 Precision：返回结果中相关文档所占比例。P = 检索出的相关文档数 / 检索出的文档总数。
- 召回率 Recall：所有相关文档中被系统检索出来的比例。R = 检索出的相关文档数 / 文档库中所有相关文档数。
- F1 值：准确率和召回率的调和平均，F1 = 2PR / (P + R)。
- 准确率和召回率常存在权衡。提高返回数量可能提升召回率但降低准确率；严格筛选可能提升准确率但漏掉相关文档。
- 排序任务还可关注 MAP、MRR、NDCG 等指标。若课程未重点展开，考试中至少掌握 P、R、F1 的定义和计算。

## 九、问答系统概述

- 问答系统 Question Answering 是直接针对用户自然语言问题返回答案的系统。它比普通检索更进一步，不只是返回文档列表，而是尽量返回具体答案。
- 常见类型包括检索式问答、知识库问答、阅读理解式问答、生成式问答。
- 检索式问答：先检索相关文档或问答对，再抽取或匹配答案。优点是可控、答案有来源；缺点是依赖文档库覆盖。
- 知识库问答：把问题解析成实体和关系，在知识图谱或结构化数据库中查询答案。优点是精确、可解释；缺点是依赖知识库完整性和问题解析。
- 阅读理解式问答：给定篇章和问题，模型从篇章中抽取答案片段。BERT 类模型常用于预测答案起止位置。
- 生成式问答：模型直接生成答案，表达自然、覆盖灵活；缺点是可能产生事实错误，需要检索增强或约束。

## 课后题答题要点

- VSM 三个关键点：文档/查询表达，相关度评估，排序返回。展开时可写预处理、标引、TF-IDF、余弦相似度、top N。
- LSI 相对 VSM 的优势：通过隐语义空间缓解同义词、多义词和噪声问题，并实现降维。
- C、U、V^T、Sigma：C 是原始词文档矩阵；U 是词项-语义维度矩阵；Sigma 是奇异值重要性矩阵；V^T 是语义维度-文档矩阵。
- 问答系统概念：用自然语言问题作为输入，返回具体答案；类型包括检索式、知识库、阅读理解式、生成式。

## 考前速记

- IR = 文档库 + 查询 + 相关度排序。
- VSM 流程：预处理 -> 标引 -> 相似度 -> 排序。
- TF-IDF：文档内高频重要，全库高频降权。
- 余弦相似度：点积除以模长乘积。
- LSI：C = U Sigma V^T，截断 SVD 得隐语义空间。
- 评测：Precision 看返回准不准，Recall 看找全没找全。

## 名词解释清单

- 信息检索：从大规模非结构化数据中找出满足用户信息需求资料的过程。
- 标引：把文档和查询转换为统一数学表示的过程。
- VSM：用向量表示文档和查询并计算相似度的检索模型。
- TF-IDF：结合词频和逆文档频率的词项权重。
- 余弦相似度：通过向量夹角余弦值衡量相似度。
- LSI：用 SVD 构造隐语义空间的检索方法。
- 问答系统：直接针对自然语言问题返回答案的系统。

## 易混点

- 检索系统返回的是有序列表，排序质量和是否命中同样重要。
- TF 高不一定重要，全库都高频的词要被 IDF 降权。
- VSM 基于表层词项，LSI 试图转到隐语义维度。
- Precision 和 Recall 分母不同：前者看返回结果，后者看全部相关文档。
