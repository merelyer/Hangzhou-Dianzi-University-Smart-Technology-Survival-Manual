# 魔方机器人运动规划系统

## 项目概述

本项目是一套用于魔方机器人的运动规划系统，包含碰撞检测、运动轨迹优化和S曲线运动控制算法。系统通过精确的几何计算和凸优化方法，确保魔方机器人在高速旋转和翻转操作中避免碰撞，并实现平滑高效的运动控制。

## 文件功能说明

### 文档1: `finger_vs_arm_angle.py`
- **功能**: 魔方与机械臂的碰撞检测与最小安全距离计算
- **核心特性**:
  - 使用trimesh库进行精确的3D碰撞检测
  - 通过二分法搜索计算不同角度下的最小手指间距
  - 提供交互式3D可视化界面
  - 预计算0-90度范围内所有角度对应的最小偏移量

### 文档2: `motion_adjust_arm.py`
- **功能**: 同侧旋转臂与手指联动控制
- **核心特性**:
  - 使用S曲线算法控制旋转臂运动
  - 凸优化方法生成手指运动轨迹
  - 极坐标可视化手指运动路径
  - 支持速度、加速度和加加速度约束

### 文档3: `motion_flip_and_adjust_180.py`
- **功能**: 魔方翻转同时对侧手臂旋转180度的联动控制
- **核心特性**:
  - 双电机协同控制（翻转电机和调整电机）
  - 复杂的三阶段运动规划
  - 基于预计算的最小偏移量数据
  - 多轴运动轨迹优化

### 文档4: `motion_flip_and_adjust.py`
- **功能**: 魔方翻转同时对侧手臂旋转±90度的联动控制
- **核心特性**:
  - 支持正向和反向90度旋转
  - 统一的运动规划框架
  - 实时碰撞避免算法
  - 完整的运动数据输出

### 文档5: `motion_flip.py`
- **功能**: 单纯魔方翻转操作的对侧手指避让控制
- **核心特性**:
  - 90度和180度翻转支持
  - 对侧手指自动避让轨迹生成
  - 简化版的运动规划算法

### 文档6: `scurve.py`
- **功能**: S曲线运动控制算法库
- **核心特性**:
  - 7段式S曲线加速度规划
  - 支持速度、加速度、加加速度限制
  - 多种运动状态管理
  - 精确的运动学计算

### 文档7: `table.py`
- **功能**: 运动数据表生成器
- **核心特性**:
  - 自动调用各运动规划模块
  - 生成C语言格式的运动数据表
  - 数据范围验证和格式化
  - 配置文件自动生成

### 文档8: `test_scurve.py`
- **功能**: S曲线算法演示
- **核心特性**:
  - S曲线运动 profile 可视化
  - 位置、速度、加速度、加加速度曲线显示
  - 算法性能评估

## 安装依赖

pip install numpy matplotlib trimesh python-fcl cvxpy ecos


## 运行说明

1. **碰撞检测预计算**:
   python finger_vs_arm_angle.py


2. **运动规划测试**:
   python motion_adjust_arm.py
   python motion_flip_and_adjust.py


3. **生成运动数据表**:
   python table.py


4. **S曲线演示**:
   python test_scurve.py


## 应用场景

本系统专为魔方解算机器人设计，适用于:
- 高速魔方旋转操作的运动规划
- 多轴协同运动的碰撞避免
- 实时运动控制算法的开发与测试
- 嵌入式系统的运动数据预计算

## 技术特点

- **精确性**: 使用精确的3D碰撞检测算法
- **高效性**: 凸优化方法生成最优运动轨迹
- **安全性**: 确保所有运动都在安全范围内
- **可视化**: 提供丰富的运动轨迹可视化工具
- **嵌入式友好**: 生成可直接用于嵌入式系统的数据表
