# 杭电智能科学与技术生存手册

> 一份从课堂、实验、期末、项目到自救路线的本科课程资料库。  
> 不是资料堆，是智科人的作战地图。

## 这是什么

这里收纳的是杭州电子科技大学智能科学与技术相关本科课程资料，覆盖电子电路、信号处理、控制、数据结构、机器学习、深度学习、机器视觉、机器人、自然语言处理、项目管理等方向。

它的目标很简单：

- 让后来者少走弯路。
- 让复习不再从零开始。
- 让课程、实验、项目资料有一个能检索、能继承、能继续进化的根据地。

## 使用方式

1. 先按课程文件夹定位资料。
2. 复习优先看课件、往年题、整理笔记。
3. 实验优先看报告、代码、数据说明，再跑环境。
4. 项目资料不要盲交，先改成自己的理解和实现。

## 上传说明

当前本地资料体量较大，包含数据集、模型权重、压缩包和大量图片/XML 标注文件。普通 GitHub 仓库会拒绝超过 100MB 的文件；如果需要全量保留，应使用 Git LFS、Release 或外部网盘链接。

建议仓库采用两层结构：

- GitHub 仓库：README、课程索引、轻量资料、代码、笔记、报告。
- 大文件存储：数据集、模型权重、超大压缩包、完整教材包。
