- 移动机器人运动学建模。

- 位姿表示与坐标变换。

## 三、基本概念

### 1. 位姿

移动机器人在二维平面中的位姿通常表示为：

```text
q = [x, y, theta]^T
```

其中：

- `x, y`：机器人在全局坐标系中的位置。
- `theta`：机器人朝向角。

三维空间中刚体位姿通常需要6个自由度：

- 位置：x、y、z。
- 姿态：roll、pitch、yaw，或旋转矩阵、四元数表示。

### 2. 坐标系

常见坐标系：

- 世界坐标系：描述环境中物体的全局位置。
- 机器人坐标系：固定在机器人本体上。
- 传感器坐标系：固定在相机、激光雷达、IMU等传感器上。
- 地图坐标系：定位和建图中使用的坐标系。

坐标变换是运动控制和感知融合的基础。

### 3. 运动学

运动学研究机器人位置、姿态、速度之间的几何关系，不考虑力和力矩。

移动机器人控制中常用运动学模型描述：

- 线速度。
- 角速度。
- 轮速。
- 位姿变化。

### 4. 动力学

动力学研究力、力矩、质量、惯量与运动之间的关系。

对高速运动、足式机器人、机械臂、高动态平台，动力学控制更重要。

## 四、差动轮机器人运动学

差动轮机器人由左右两个驱动轮控制运动。

设：

- 左轮速度为 `v_l`。
- 右轮速度为 `v_r`。
- 两轮间距为 `L`。
- 车体线速度为 `v`。
- 车体角速度为 `omega`。

常用关系：

```text
v = (v_r + v_l) / 2
omega = (v_r - v_l) / L
```

若轮半径为 `r`，左右轮角速度分别为 `omega_l`、`omega_r`：

```text
v_l = r * omega_l
v_r = r * omega_r
```

则：

```text
v = r(omega_r + omega_l) / 2
omega = r(omega_r - omega_l) / L
```

平面位姿变化：

```text
x_dot = v cos(theta)
y_dot = v sin(theta)
theta_dot = omega
```

复习重点：

- 左右轮同速：直线。
- 左右轮反向同速：原地旋转。
- 左右轮不同速：圆弧运动。

## 五、非完整约束

普通轮式机器人不能沿车体侧向直接滑动，因此满足非完整约束。

对差动轮机器人：

```text
-sin(theta) * x_dot + cos(theta) * y_dot = 0
```

含义：

- 机器人瞬时速度方向必须沿车体前进方向。
- 不能像全向机器人一样直接横移。

考试常问：

- 非完整约束不是位置约束，而是速度约束。
- 非完整机器人仍可能通过前进、转向组合到达平面任意位置。

## 六、阿克曼转向模型

阿克曼转向类似汽车。

设：

- 后轴中心速度为 `v`。
- 轴距为 `L`。
- 前轮转角为 `delta`。

常用模型：

```text
x_dot = v cos(theta)
y_dot = v sin(theta)
theta_dot = v tan(delta) / L
```

特点：

- 不能原地转向。
- 最小转弯半径受前轮最大转角限制。
- 适合车辆、无人车等高速平台。

## 七、全向机器人运动控制

全向机器人可在平面内实现：

- x方向速度。
- y方向速度。
- 绕自身旋转角速度。

控制目标通常表示为：

```text
V = [v_x, v_y, omega]^T
```

再通过运动学逆解分配到各个全向轮或麦克纳姆轮。

特点：

- 机动性强。
- 路径跟踪更灵活。
- 轮地摩擦和地面条件对精度影响大。

## 八、PID控制

PID是机器人底层控制最常见方法之一。

控制律：

```text
u(t) = Kp * e(t) + Ki * integral(e(t)) + Kd * de(t)/dt
```

其中：

- P：比例项，快速响应误差。
- I：积分项，消除稳态误差。
- D：微分项，抑制超调、改善动态响应。

### PID参数影响

`Kp`过小：

- 响应慢。
- 误差消除慢。

`Kp`过大：

- 容易超调。
- 可能振荡。

`Ki`过大：

- 积分饱和。
- 超调增大。

`Kd`过大：

- 对噪声敏感。
- 控制输出抖动。

### 常见应用

- 电机速度控制。
- 轮速闭环。
- 角度控制。
- 路径横向误差控制。

## 九、轨迹跟踪与路径跟踪

### 1. 路径

路径只描述空间几何曲线，不强调时间。

例子：

- 从A点到B点的一条曲线。
- 地图中的一串路径点。

### 2. 轨迹

轨迹包含时间信息。

例子：

- 在第1秒到达某点，第2秒到达另一点。
- 包含位置、速度、加速度随时间变化。

### 3. 路径跟踪

路径跟踪目标是让机器人尽量贴近给定路径。

常见误差：

- 横向误差。
- 航向误差。
- 距离目标点误差。

### 4. 轨迹跟踪

轨迹跟踪不仅要求位置正确，还要求在规定时间达到相应状态。

适合：

- 高速运动。
- 多机器人协同。
- 动态避障。

## 十、常见路径跟踪方法

### 1. Pure Pursuit纯追踪

核心思想：

机器人在路径前方选取一个预瞄点，并控制机器人朝该点运动。

关键参数：

- 预瞄距离。

预瞄距离太小：

- 跟踪精度高但容易振荡。

预瞄距离太大：

- 运动平滑但转弯切角明显。

### 2. Stanley控制

常用于无人车路径跟踪。

综合考虑：

- 航向误差。
- 横向误差。

特点：

- 对道路跟踪有效。
- 速度变化时需要调参。

### 3. 反馈线性化

通过数学变换将非线性系统转化为更容易控制的形式。

适合理论分析，但实际应用中要考虑模型误差和执行器限制。

### 4. 模型预测控制 MPC

MPC在预测时间窗口内优化控制输入。

优点：

- 可处理约束。
- 可综合考虑轨迹误差、控制平滑性、速度限制等。

缺点：

- 计算量大。
- 依赖模型准确性。

## 十一、运动控制系统层次

机器人运动控制常分层：

### 1. 任务层

决定机器人要做什么。

例子：

- 去目标点。
- 巡逻。
- 搬运。
- 搜索区域。

### 2. 规划层

决定怎么走。

输出：

- 路径。
- 轨迹。
- 速度规划。

### 3. 控制层

根据规划结果生成控制命令。

输出：

- 线速度。
- 角速度。
- 轮速。
- 关节力矩。

### 4. 执行层

由电机、驱动器、执行机构完成动作。

## 十二、运动控制中的实际问题

### 1. 传感器误差

编码器打滑、IMU漂移、定位误差都会影响控制效果。

### 2. 执行器限制

控制命令不能超过：

- 最大速度。
- 最大加速度。
- 最大电流。
- 最大转角。
- 最大力矩。

### 3. 延迟

通信、计算、传感器采样和执行器响应都会产生延迟，可能导致超调和振荡。

### 4. 地面条件

轮式机器人受地面摩擦影响明显。湿滑、松软、不平地面会造成打滑和模型误差。

### 5. 安全

运动控制必须考虑：

- 障碍物。
- 人机安全距离。
- 急停。
- 速度限制。
- 失控保护。

## 十三、易混点

### 1. 运动学和动力学

运动学：研究位置、速度、姿态之间关系。

动力学：研究力、力矩与运动之间关系。

### 2. 路径和轨迹

路径：只有空间几何。

轨迹：包含时间、速度、加速度。

### 3. 开环和闭环

开环控制：不利用反馈修正误差。

闭环控制：根据传感器反馈实时修正误差。

机器人实际控制一般需要闭环。

### 4. 规划和控制

规划决定理想路线或轨迹。

控制负责让机器人实际运动跟上规划结果。

## 十四、常见考点

### 简答题：差动轮机器人如何由左右轮速度得到线速度和角速度？

答题要点：

左右轮线速度分别为 `v_l` 和 `v_r`，轮距为 `L`，则机器人线速度为两轮速度平均值，角速度为左右轮速度差除以轮距：

```text
v = (v_r + v_l) / 2
omega = (v_r - v_l) / L
```

### 简答题：什么是非完整约束？

答题要点：

非完整约束是无法积分成纯位置约束的速度约束。差动轮机器人不能瞬时侧向移动，因此其速度必须沿车体前进方向，属于典型非完整约束系统。

### 简答题：PID三个环节的作用

答题要点：

比例项根据当前误差产生控制作用，积分项消除长期稳态误差，微分项根据误差变化趋势抑制超调和振荡。

### 简答题：轨迹跟踪与路径跟踪的区别

答题要点：

路径跟踪只要求机器人沿空间路径运动，不严格要求时间；轨迹跟踪要求机器人按给定时间序列到达指定位置、速度或姿态。

## 十六、背诵版小结

机器人运动控制的核心是根据任务和规划结果，使机器人稳定、准确、安全地完成运动。移动机器人通常用位姿表示状态，用运动学模型描述速度与位姿变化关系。差动轮机器人线速度为左右轮速度平均值，角速度由左右轮速度差决定；普通轮式机器人具有非完整约束，不能瞬时侧向移动。运动控制常采用PID、路径跟踪、轨迹跟踪和模型预测控制等方法，并需要考虑传感器误差、执行器限制、地面条件和安全约束。
