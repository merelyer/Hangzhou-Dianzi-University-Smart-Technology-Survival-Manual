## 二、移动机器人平台的基本组成

一个典型智能移动机器人平台通常包括：

- 机械结构：底盘、机架、轮/腿/履带、传动机构。
- 驱动系统：电机、液压、气压或复合驱动。
- 控制系统：嵌入式控制器、工控机、运动控制板。
- 传感系统：编码器、IMU、激光雷达、相机、超声波等。
- 能源系统：电池、电源管理、稳压模块。
- 通信系统：有线通信、Wi-Fi、CAN、EtherCAT等。
- 软件系统：操作系统、驱动程序、中间件、算法模块。

平台性能直接影响机器人能否完成任务。运动机构决定机器人“怎么走”，驱动系统决定“能不能动、动得多快多稳”，软件系统决定各模块能否协同工作。

## 三、地面移动机器人的行走机构

常见地面移动机器人行走机构：

- 轮式行走机构。
- 腿式行走机构。
- 履带式行走机构。
- 复合式行走机构。

选择运动机构时要综合考虑：

- 地形类型：平地、草地、台阶、碎石、坡道、灾后环境等。
- 速度要求：快速巡航还是低速越障。
- 能耗要求：续航时间和功率限制。
- 稳定性要求：是否需要动态平衡。
- 控制复杂度：算法和硬件实现难度。
- 成本和维护：结构复杂度、易损件、维修便利性。

## 四、轮式运动机构

### 1. 轮式运动的优点

轮式运动在平坦地面上效率很高，是移动机器人最常见的运动方式。

优点：

- 运动速度快。
- 能耗较低。
- 机械结构相对简单。
- 稳定性较好。
- 控制难度相对较低。
- 适合室内、道路、仓储、服务等结构化环境。

### 2. 轮式运动的缺点

缺点：

- 对地面平整度依赖强。
- 粗糙、不平、松软地形下性能下降。
- 越障能力弱于腿式和履带式。
- 普通轮式平台横向运动能力有限。

### 3. 轮式运动关注的核心问题

- 牵引力：轮子与地面之间是否有足够摩擦。
- 稳定性：机器人运动中是否容易倾覆或打滑。
- 机动性：是否能灵活转向、原地旋转、狭小空间运动。
- 速度控制：能否准确控制线速度和角速度。

### 4. 差动轮式机构

差动运动轮系通常由两个轴线平行的驱动轮和一个或多个从动轮组成。

工作原理：

- 两驱动轮速度相同：机器人直线运动。
- 一个驱动轮速度为零，另一个不为零：机器人绕静止轮接地点旋转。
- 两轮速度大小或方向不同：机器人产生曲线运动或原地旋转。

差动驱动特点：

- 结构简单。
- 可实现原地转向。
- 控制方便。
- 属于平面内非完整约束系统。

非完整约束含义：

机器人运动受到速度约束，不能任意瞬时向侧向平移。例如普通差动轮机器人不能直接横向移动。

### 5. 阿克曼转向

阿克曼转向类似汽车转向机构。

特点：

- 适合高速、道路场景。
- 运动平稳。
- 转弯半径受限制，不能原地旋转。
- 控制中需要考虑前轮转角与车体运动半径的关系。

### 6. 全向运动机构

全向运动指机器人可以在平面内向任意方向运动，包括前后、左右和旋转。

实现方式：

- 球形轮。
- 全向轮。
- 麦克纳姆轮。
- 三轮或四轮全向平台。

优点：

- 狭小空间机动性强。
- 可横向移动。
- 适合足球机器人、仓储机器人、服务机器人等。

缺点：

- 结构和控制比普通轮式复杂。
- 对地面平整度要求较高。
- 轮地接触和摩擦特性影响控制精度。

## 五、腿式运动机构

### 1. 腿式运动的优势

自然界偏爱腿式运动，因为自然环境往往粗糙、非结构化、不平整。

优势：

- 地形适应性强。
- 可跨越障碍。
- 可在台阶、碎石、斜坡、复杂地形中运动。
- 可通过选择落脚点提高通过性。
- 适合救援、巡检、野外探测等场景。

### 2. 腿式运动的劣势

劣势：

- 机械结构复杂。
- 驱动器数量多。
- 控制难度高。
- 能耗较高。
- 动态平衡问题突出。
- 成本和维护要求高。

### 3. 腿的数量与复杂度

腿的数量影响机械复杂度和控制复杂度。

- 单腿：需要跳跃和平衡控制，研究价值高。
- 双腿：接近人类运动，但稳定性和动态控制难度大。
- 四腿：稳定性和机动性折中，应用较多。
- 六腿：静态稳定性强，但机构复杂、效率较低。

### 4. 腿的自由度

腿式移动机器人的腿至少需要两个自由度：

- 抬腿。
- 向前摆腿。

增加自由度可以提高机动性，但会带来：

- 更多关节和执行器。
- 更高质量和功耗。
- 更复杂的控制算法。
- 更高成本。

### 5. 被动行走思想

被动行走利用机械结构本身的自然动力学特性，例如摆和弹簧的周期振荡，减少主动驱动和控制能耗。

意义：

- 提高能效。
- 利用机械结构简化控制。
- 启发足式机器人设计。

## 六、履带式运动机构

### 1. 履带式机构原理

履带由连接到驱动齿轮、轮子或链轮的一组连杆组成，沿机器人底盘类似传送带方式运行。

### 2. 履带式优点

- 接地面积大。
- 牵引力强。
- 越障能力强。
- 稳定性好。
- 在松软、泥泞、碎石地形上通过性较好。

### 3. 履带式缺点

- 速度通常较慢。
- 能耗较高。
- 履带可能脱落、卡住或撕裂。
- 履带和驱动机构之间可能夹入异物。
- 修理维护相对困难。

### 4. 应用场景

- 救援机器人。
- 军用侦察机器人。
- 工程机器人。
- 灾后复杂环境移动平台。

## 七、复合式运动机构

复合式机构将轮式、腿式、履带式等机构组合，利用不同机构的优势提升综合性能。

常见形式：

- 轮腿式。
- 轮履式。
- 腿履式。
- 可变形底盘。

### 1. 轮腿式

特点：

- 轮式模式下高速、高效。
- 腿式或腿轮结合模式下提升越障能力。

代表例子：

- Boston Dynamics Handle。
- KAIST DRC-HUBO等轮腿结合平台。

### 2. 轮履式

特点：

- 轮式模式用于快速行驶。
- 履带模式用于越障、爬坡、复杂地形。

适合场景：

- 需要在障碍之间快速移动，又需要越过台阶、坡道或沟壑。

## 八、运动机构设计流程

课件给出的设计过程可整理为：

1. 需求分析：任务分析和环境分析，确定性能指标和设计参数。
2. 确定工作原理和结构类型，绘制原理图或机构运动简图。
3. 进行受力分析、运动学分析和动力学分析。
4. 计算运动参数和动力参数。
5. 确定动力源和传动方式。
6. 3D建模，完成结构设计和材料选择。
7. 特性分析：应力、强度、刚度、抗磨性、耐热性、振动稳定性、惯性参数等。
8. 绘制总装配图、部件装配图和零件图。
9. 加工、安装、调试。
10. 迭代改进。

## 九、轮式设计案例要点

课件案例涉及室外复杂地形比赛任务。

任务环境：

- 草坪。
- 斜坡：约15度到45度。
- 台阶：高度不超过0.5米。
- 悬崖/落差：高度不超过1米。
- 随机障碍物。
- 总距离不超过800米。

性能指标：

- 车体宽度不超过2米。
- 天线高度不超过3米。
- 重量不大于70kg。
- 最大行驶速度大于1.2m/s。
- 具备遥控驾驶能力。
- 能与遥控站通信，回传状态信息。
- 通信中断时具备一定自主行驶能力。
- 能爬坡、上台阶、下台阶。

案例启示：

- 设计首先由任务需求驱动。
- 不能只追求速度，还要考虑越障和安全。
- 室外复杂地形常需要复合式机构。
- 机器人平台设计必须在性能、重量、成本、能耗之间折中。

## 十、机器人驱动方式

驱动系统相当于机器人的“肌肉”，负责驱动机械系统动作。

按驱动源不同，可分为：

- 电气驱动。
- 液压驱动。
- 气压驱动。
- 综合驱动。
- 新型驱动方式。

### 1. 电气驱动

电气驱动最常见，主要是电机驱动。

优点：

- 控制精度高。
- 响应快。
- 便于数字控制。
- 易与传感器、控制器集成。
- 维护相对方便。

常见电机：

- 舵机。
- 有刷直流伺服电机。
- 无刷直流伺服电机。
- 步进电机。

### 2. 舵机

舵机是一种位置或角度伺服驱动装置。

适用：

- 需要角度变化并保持位置的控制系统。
- 小型机器人关节。
- 云台。
- 简单机械机构。

### 3. 有刷直流电机

原理：

- 机械换向。
- 磁极固定，线圈旋转。
- 由直流电直接产生扭矩。

优点：

- 成本低。
- 控制简单。
- 可靠性较高。

缺点：

- 电刷磨损。
- 高强度使用寿命较低。
- 维护需求较高。
- 电磁干扰相对较大。

### 4. 无刷直流电机

原理：

- 电子换向。
- 线圈不动，磁极旋转。
- 通过霍尔元件等检测转子位置，控制线圈电流方向。

优点：

- 高功率重量比。
- 可高速运行。
- 电子控制性能好。
- 无电刷、干扰低、寿命长。

常用于：

- 移动机器人驱动轮。
- 无人机。
- 足球机器人。
- 高性能伺服系统。

### 5. 步进电机

步进电机将电脉冲信号转化为角位移或线位移。

特点：

- 收到一个脉冲转动固定角度。
- 转速与脉冲频率成正比。
- 停止位置与脉冲数有关。
- 开环控制简单。

优点：

- 可靠性高。
- 控制简单。
- 成本较低。

缺点：

- 难以获得高转速和大转矩。
- 可能丢步。
- 高性能应用常需闭环控制。

### 6. 电机选型考虑因素

选型时要回答：

- 负载需要多大转矩。
- 最大运动速度是多少。
- 不同负载下持续工作多久。
- 需要多大加速度。
- 转动惯量多大。
- 电机最高电压限制。
- 电流限制。
- 减速比如何选择。
- 是否需要编码器反馈。

### 7. 液压驱动

优点：

- 驱动力或驱动力矩大。
- 功率重量比高。
- 响应快。
- 易于实现大负载直接驱动。

缺点：

- 需要压力源和复杂管路。
- 成本较高。
- 油液泄漏会影响稳定性和定位精度。
- 维护复杂。

适合：

- 大负载机器人。
- 工程机械。
- 高功率足式机器人。

### 8. 气压驱动

气压驱动通常由压缩空气或压缩惰性气体提供动力。

优点：

- 速度快。
- 结构简单。
- 维修方便。
- 价格较低。

缺点：

- 空气可压缩，速度稳定性较差。
- 难以实现高精度伺服控制。

适合：

- 简单快速动作。
- 夹持、推拉、轻载执行机构。

### 9. 新型驱动方式

课件提到：

- 线牵/拉索驱动。
- 形状记忆合金。
- 离子交换聚合金属材料等智能材料驱动。

特点：

- 结构可柔性化、轻量化。
- 适合仿生机器人、柔性机器人。
- 但控制、效率、寿命和输出能力仍是难点。

## 十一、机器人操作系统 ROS

### 1. ROS定义

ROS是Robot Operating System的缩写，是开源的机器人元操作系统。

它不是传统意义上的单一操作系统，而是提供机器人软件开发所需的中间件、工具链和生态系统。

ROS提供：

- 底层设备控制。
- 程序包管理。
- 消息通信。
- 分布式计算。
- 代码获取、编译、编辑工具。
- 可视化和调试工具。

### 2. ROS的意义

ROS已经成为机器人软件事实标准之一。

原因：

- 模块化设计。
- 支持分布式计算。
- 丰富的开源算法包。
- 强大的调试工具。
- 便于复用传感器驱动和算法。

### 3. ROS计算图

ROS底层提供点对点通信架构，实现模块间松耦合网络连接和协同计算。

核心概念：

- Master。
- Node。
- Topic。
- Message。
- Service。
- Parameter Server。
- Bag。

### 4. Master

Master提供名称注册和查找功能，类似域名服务器。

作用：

- 管理节点注册。
- 维护话题、服务等通信关系。
- 帮助节点彼此发现。

启动命令通常为：

```bash
roscore
```

### 5. Node

节点是执行计算任务的进程。

例子：

- 激光雷达驱动节点。
- 相机采集节点。
- 定位节点。
- 路径规划节点。
- 底盘控制节点。

### 6. Topic与Message

Topic是基于发布/订阅机制的通信通道。

Message是Topic中传输的数据结构。

例子：

- `/scan`：激光雷达数据。
- `/odom`：里程计数据。
- `/cmd_vel`：速度控制命令。
- `/camera/image`：图像数据。

发布/订阅优点：

- 模块之间松耦合。
- 一个发布者可被多个订阅者使用。
- 适合连续数据流。

### 7. Service

Service基于请求/应答机制。

适合：

- 有明确请求和返回的任务。
- 参数查询。
- 启动/停止某功能。
- 地图保存。

与Topic区别：

- Topic适合持续数据流。
- Service适合一次性请求响应。

### 8. Parameter Server

参数服务器用于集中存储参数，节点可以查询参数值。

常见参数：

- 传感器配置。
- 坐标系名称。
- 控制器增益。
- 地图分辨率。
- 机器人尺寸。

### 9. rosbag

rosbag用于记录和重现ROS数据。

作用：

- 选择性录制话题。
- 高保真回放数据。
- 便于算法调试。
- 便于数据共享和复现实验。

## 十二、ROS常用工具

### 1. RViz

RViz是3D显示工具。

可显示：

- 3D地图。
- 传感器数据。
- 机器人模型。
- 机器人关节状态。
- 机器人运动轨迹。
- 坐标系。
- 调试标记。

### 2. rqt_bag

用于数据记录与重现。

功能：

- 查看bag文件。
- 按时间轴查看话题数据。
- 可视化图像等数据。

### 3. rqt_graph

用于查看节点和节点间通信关系。

复习点：

- 可以快速理解系统中哪些节点发布/订阅了哪些话题。

### 4. rqt_plot

用于实时绘制曲线。

适合观察：

- 速度。
- 位置误差。
- 控制输入。
- 传感器数值变化。

### 5. 命令行工具

常用工具：

- `rostopic`：查看、发布、记录话题。
- `rosservice`：查看和调用服务。
- `rosnode`：查看节点。
- `rosparam`：查看和设置参数。
- `rosmsg`：查看消息类型。

## 十三、易混点

### 1. 轮式、腿式、履带式对比

轮式：效率高、速度快、控制简单，但越障弱。

腿式：地形适应性强、可跨越障碍，但控制复杂、能耗高。

履带式：牵引力强、越障好、稳定性高，但维护难、速度慢、能耗高。

复合式：综合多种优点，但结构和控制更复杂。

### 2. 有刷电机和无刷电机

有刷电机：机械换向，成本低，控制简单，但寿命和维护受电刷限制。

无刷电机：电子换向，寿命长、功率重量比高，但控制器更复杂。

### 3. Topic和Service

Topic：发布/订阅，适合连续数据。

Service：请求/响应，适合一次性任务。

### 4. ROS不是单纯操作系统

ROS更准确地说是机器人软件中间件和工具生态，运行在Linux等操作系统之上。

## 十四、常见考点

### 简答题：轮式机器人的优缺点

答案要点：

- 优点：速度快、能耗低、结构简单、稳定性较好、控制容易。
- 缺点：对地面平整度依赖强，粗糙和不平地形通过性差，普通轮式横向机动能力不足。

### 简答题：腿式机器人为什么控制复杂？

答案要点：

- 关节和自由度多。
- 接触状态不断切换。
- 需要实时保持平衡。
- 需要规划落脚点和步态。
- 动力学强非线性。
- 对传感器和执行器性能要求高。

### 简答题：履带式机器人的优缺点

答案要点：

- 优点：牵引力大、稳定性好、越障能力强、适合复杂地形。
- 缺点：履带易脱落或卡住、维护困难、能耗高、速度较慢。

### 简答题：机器人运动机构设计流程

答案要点：

需求分析、原理和结构确定、运动学动力学分析、动力源与传动方式选择、三维建模、结构和材料设计、强度刚度等特性分析、工程图纸、加工装配调试、迭代改进。

### 简答题：ROS计算图的核心概念

答案要点：

Master负责注册和查找，Node执行计算任务，Topic和Message实现发布/订阅通信，Service实现请求/响应通信，Parameter Server集中管理参数，Bag用于数据记录与回放。

## 十六、背诵版小结

智能机器人平台由机械结构、驱动系统、控制系统、传感系统、能源通信系统和软件系统构成。地面移动机器人常用轮式、腿式、履带式和复合式运动机构。轮式效率高但越障弱，腿式地形适应性强但控制复杂，履带式牵引力和越障能力强但维护困难，复合式兼顾多种能力但复杂度高。驱动系统包括电气、液压、气压和新型驱动，其中电机驱动最常用。ROS作为机器人元操作系统，通过节点、话题、消息、服务、参数服务器和工具链实现模块化、分布式机器人软件开发。
