## 二、传感器的作用和地位

传感器是机器人智能化的基础，是执行各种任务的前提。

机器人需要感知：

- 自身状态：速度、加速度、姿态、关节角、轮速、电量等。
- 周围环境：亮度、颜色、距离、障碍物、目标、人、地形等。

没有传感器，机器人只能执行预设动作；有了传感器，机器人才能根据环境反馈进行定位、建图、避障、识别、交互和控制。

## 三、传感器分类

### 1. 按是否主动发射能量

被动传感器：

- 不主动发射能量。
- 直接接收环境信号。
- 例子：普通相机、麦克风、温度传感器。

主动传感器：

- 向环境发射能量。
- 测量反射信号。
- 例子：激光雷达、超声波、结构光深度相机。

### 2. 按感知对象

内部传感器：

- 用于监测机器人内部状态。
- 例子：编码器、IMU、电流传感器、关节角传感器。

外部传感器：

- 用于感知周围环境。
- 例子：相机、激光雷达、超声波、毫米波雷达、触觉传感器。

## 四、典型机器人传感器系统案例

### 1. 无人驾驶汽车Boss

Boss搭载多种传感器：

- GPS接收器。

- 二维激光雷达。
- 惯性测量单元。
- 毫米波雷达等。

意义：

- 单一传感器很难满足复杂自动驾驶任务。
- 多传感器融合可以提高可靠性和环境理解能力。

### 2. PR2机器人

PR2搭载：

- 云台激光雷达。
- Kinect RGB-D相机。
- IMU。
- 高清相机。
- 广角双目相机。
- Hokuyo激光雷达等。

意义：

- 服务机器人需要同时进行移动、操作和交互。
- 需要感知头部、底盘、机械臂等多个层面的信息。

### 3. 好奇号火星车

好奇号使用多种科学传感器：

- 化学相机。
- 彩色相机。
- 矿物分析仪。
- 火星车环境监测站。

意义：

- 极端环境机器人需要传感器支持科学探测和自主运行。

## 五、内部状态传感器

### 1. 增量式光电编码器

组成：

- 光栅转盘。
- 光源。
- 感光器件。
- 信号处理电路。

原理：

- 将机械转角转换为正弦波或方波电信号。
- 脉冲数量与旋转角度成正比。
- 光栅数量决定角度测量精度。

用途：

- 轮速测量。
- 关节角度测量。
- 里程计估计。

注意：

- 增量式编码器通常测量相对位移。
- 断电后绝对位置可能丢失，需要回零或初始标定。

### 2. 霍尔效应编码器

霍尔编码器根据霍尔效应，将磁场转动转化为输出电压变化。

特点：

- 可测量绝对位置。
- 结构紧凑。
- 可通过多个霍尔元件提高精度。

### 3. 加速度计

加速度计可建模为弹簧-质量块-阻尼系统。

稳定状态下可近似理解为：

```text
m a = k x
```

其中：

- `m`：敏感质量。
- `k`：弹性系数。
- `x`：位移。
- `a`：加速度。

重要理解：

- 加速度计测量的是作用在载体上的合加速度，包括重力影响。
- 若要获得实际运动加速度，需要剔除重力分量。
- 对加速度积分得到速度，二次积分得到位置，但误差会随积分放大。
- 自由落体时，加速度计输出可能接近0。

### 4. 陀螺仪

陀螺仪用于测量角速度。

用途：

- 姿态估计。
- 航向角变化估计。
- 与加速度计融合构成IMU。

### 5. 惯性测量单元 IMU

IMU通常包含：

- 三轴加速度计。
- 三轴陀螺仪。

有些IMU还包含磁力计。

特点：

- 输出频率高。
- 能反映机器人瞬时运动。
- 存在累积误差和漂移。
- 常与GPS、视觉、激光雷达等融合校正。

## 六、测距传感器

### 1. 飞行时间测距 ToF

基本思想：

传感器发射声波或光波，测量信号往返目标的飞行时间，从而计算距离。

公式：

```text
d = v * t / 2
```

其中：

- `d`：目标距离。
- `v`：波传播速度。
- `t`：往返时间。
- 除以2是因为信号经历了去程和回程。

### 2. 超声波测距

原理：

- 利用压电晶片等超声换能器发射超声波。
- 声波经物体反射后被接收。
- 根据发射与接收时间差计算距离。

特点：

- 超声波频率高于20kHz。
- 方向性较好。
- 几乎不受光线、粉尘、烟雾、电磁干扰影响。
- 典型频率约40kHz到180kHz。
- 低频通常对应更大量程。
- 分辨率约厘米级。
- 测量误差常在百分之几量级。

缺点：

- 波束角较大，测到的是某区域深度。
- 容易受物体材质、入射角、空气温度影响。
- 精度和分辨率低于激光雷达。

应用：

- 近距离避障。
- 简单测距。
- 低成本机器人环境感知。

### 3. ToF激光雷达

原理：

- 主动发射红外激光脉冲。
- 接收目标反射脉冲。
- 测量飞行时间并结合光速计算距离。

特点：

- 激光聚焦能力强。
- 短距离内发散小。
- 光速不易受温湿度影响。
- 精度可达厘米级。

难点：

- 对时间测量精度要求极高。
- 1纳秒光脉冲约移动0.3米。
- 若要厘米级精度，需要极高时间分辨率。

### 4. 二维激光雷达

二维激光雷达通过旋转镜面或旋转机构，将单点测距扩展为平面扫描。

用途：

- 避障。
- 建图。
- 定位。
- 2D SLAM。

代表产品：

- SICK LMS系列。
- Hokuyo UTM、URG系列。

### 5. 三维激光雷达

三维激光雷达不局限于一个平面扫描，可以获得空间点云。

实现方式：

- 多线激光雷达。
- 二维激光雷达增加转动自由度。

代表产品：

- Velodyne 64线、32线、16线激光雷达。

应用：

- 自动驾驶。
- 三维建图。
- 障碍物检测。
- 三维SLAM。

### 6. 三角测距激光雷达

特点：

- 与ToF相比量程有限。
- 精度较低。
- 成本可能更低。
- 常用于小型平面扫描雷达。

## 七、RGB-D相机与Kinect

Kinect RGB-D相机包含：

- 红外光编码发射器。
- 红外相机。
- RGB相机。
- 麦克风阵列。
- 俯仰电机。

结构光原理：

- 红外发射器投射激光散斑。
- 散斑具有高度随机性。
- 每个局部散斑图案具有唯一性，便于识别深度。

应用：

- 三维地图创建。
- 定位。
- 避障。
- 人机交互。

## 八、机器人视觉

### 1. 视觉的重要性

视觉是机器人最重要的环境感知方式之一。

优势：

- 信息丰富。
- 兼容性好。
- 成本低。
- 可用于识别、定位、建图和交互。

### 2. 相机

相机是视觉系统核心传感器。

作用：

- 将光信号转换为数字图像。
- 输出灰度图、彩色图或深度图。

## 九、针孔相机模型

### 1. 小孔成像

小孔成像模型：

- 一个小孔和一个成像平面。
- 光线只有通过小孔才能到达成像平面。
- 成像为倒立像。

问题：

- 孔太小，进光少。
- 孔太大，成像模糊。
- 孔径与光波长接近时会出现衍射。
- 容易出现暗角。

### 2. 镜头作用

镜头将光线聚焦到像平面上。

关键特性：

- 穿过光学中心的光线方向不变。
- 与光轴平行的光线聚于焦点。

### 3. 针孔近似

当物距远大于焦距时，可以用针孔模型近似相机成像。

物体成像大小与相机距离成反比：

```text
h' / h = f / z
h' = f h / z
```

其中：

- `h`：物体真实高度。
- `h'`：图像上的高度。
- `f`：焦距。
- `z`：物体到相机距离。

这说明远处物体看起来小，近处物体看起来大，这就是透视效应。

## 十、透视投影与相机坐标

### 1. 常见坐标系

世界坐标系：

- 描述相机和物体在三维世界中的绝对位置。

相机坐标系：

- 原点位于相机光心。
- Z轴通常沿光轴。
- X、Y轴与图像坐标方向相关。

图像坐标系：

- 原点通常位于像平面中心。
- 单位为物理长度。

像素坐标系：

- 原点位于图像左上角。
- 单位为像素。

### 2. 从相机坐标到图像坐标

设空间点在相机坐标系中为 `(X_c, Y_c, Z_c)`，根据相似三角形：

```text
x = f X_c / Z_c
y = f Y_c / Z_c
```

### 3. 从图像坐标到像素坐标

考虑像素尺度和主点坐标：

```text
u = u0 + k_u x
v = v0 + k_v y
```

合并可得：

```text
u = u0 + f_x X_c / Z_c
v = v0 + f_y Y_c / Z_c
```

其中：

- `f_x, f_y`：以像素为单位的焦距。
- `u0, v0`：主点坐标。

### 4. 相机内参矩阵

常写为：

```text
K = [ f_x   0   u0
      0    f_y  v0
      0     0    1 ]
```

内参描述相机自身成像特性。

### 5. 相机外参

外参包括：

- 旋转矩阵 `R`。
- 平移向量 `T`。

用于将世界坐标点转换到相机坐标系。

### 6. 完整投影关系

常见形式：

```text
s p = K [R | T] P
```

其中：

- `P`：世界坐标系中的三维点齐次坐标。
- `p`：像素坐标系中的二维点齐次坐标。
- `s`：尺度因子。
- `K`：内参。
- `[R | T]`：外参。

## 十一、镜头畸变与相机标定

### 1. 镜头畸变

由于制造加工原因，镜头存在非线性畸变。

典型径向畸变：

- 桶形畸变。
- 枕形畸变。

透视投影模型通常先不考虑畸变，实际应用中需要标定和校正。

### 2. 相机标定

相机标定的目标：

- 求相机内参。
- 求畸变参数。
- 在多相机系统中求外参。

常见方法：

- 张正友标定法。
- 棋盘格标定。

标定意义：

- 提高测量和重建精度。
- 支持视觉定位、双目测距、视觉SLAM。

## 十二、双目立体视觉

### 1. 深度信息问题

单个视角无法直接得到深度信息。普通单目相机像素只提供方向和亮度，不直接提供距离。

双目立体视觉使用两个或多个相机从不同角度成像，通过视差恢复三维信息。

### 2. 简化双目模型

假设两个相机只在x轴方向存在平移，焦距为 `f`，基线长度为 `b`。

视差：

```text
d = u_l - u_r
```

深度：

```text
Z = b f / d
```

理解：

- 视差越大，物体越近。
- 视差越小，物体越远。
- 基线越大，远距离深度分辨能力越强，但近距离匹配难度也可能增加。

### 3. 立体匹配

目标：

找出左右图像中对应同一场景点的像素、特征点或区域。

典型相似性指标：

- NCC：归一化互相关。
- SSD：平方误差和。
- SAD：绝对误差和。

问题：

- 二维穷举搜索计算量巨大。
- 纹理少、重复纹理、遮挡、光照变化都会导致匹配困难。

### 4. 对极几何约束

重要概念：

- 极点：一个相机中心在另一个像平面上的像。
- 极平面：由两个相机中心和空间点组成的平面。
- 极线：极平面与像平面的交线。

极线约束：

一个图像中的点，在另一图像中的对应点必定位于对应极线上。

意义：

- 将匹配搜索从二维降低到一维。
- 大幅减少计算复杂度。

### 5. 极线校正

极线校正也叫平行校正。

目标：

- 通过旋转、去畸变、平移等操作，将双目图像变换到简化模型。
- 使对应点位于同一水平线上。

校正后：

- 匹配只需沿水平方向搜索。
- 视差计算更简单。

### 6. 双目立体视觉流程

基本流程：

1. 相机标定。
2. 图像去畸变。
3. 极线校正。
4. 立体匹配。
5. 计算视差图。
6. 三角测量恢复深度。
7. 生成点云或深度图。

## 十三、易混点

### 1. 主动传感器和被动传感器

主动传感器发射能量并测量反射。

被动传感器只接收环境信号。

### 2. IMU能不能长期准确定位

IMU频率高、短时运动估计好，但会漂移，不能单独长期准确定位。

### 3. 单目相机为什么不能直接测深度

单幅图像缺少尺度信息，同一像素点可能对应同一视线上的多个三维点。

### 4. 相机内参和外参

内参描述相机自身成像性质。

外参描述相机相对世界坐标系的位置和姿态。

### 5. 双目基线影响

基线大：

- 远距离深度精度更好。
- 近距离遮挡和匹配难度增加。

基线小：

- 近距离匹配较容易。
- 远距离视差太小，深度精度差。

## 十四、常见考点

### 简答题：传感器为什么是机器人智能化基础？

答题要点：

机器人需要通过传感器获取自身状态和外部环境信息，才能进行定位、建图、识别、避障、规划、控制和交互。没有传感器反馈，机器人只能执行固定动作，无法适应环境变化。

### 简答题：ToF测距原理

答题要点：

传感器发射声波或光波，接收目标反射信号，测量往返飞行时间，距离等于传播速度乘以时间再除以2。

### 简答题：IMU的优缺点

答题要点：

IMU输出频率高，可反映瞬时运动，适合姿态和短时运动估计；但存在积分误差和漂移，长期使用需要与GPS、视觉、激光雷达等融合校正。

### 简答题：针孔相机模型核心公式

答题要点：

空间点投影到图像平面满足相似三角形关系：

```text
x = f X / Z
y = f Y / Z
```

物体成像大小与深度成反比。

### 简答题：双目测深公式与视差关系

答题要点：

简化双目中深度：

```text
Z = b f / d
```

视差越大，深度越小；视差越小，目标越远。

## 十六、背诵版小结

机器人传感器用于获取自身状态和外部环境信息，是机器人智能化的基础。传感器可分为主动/被动、内部/外部传感器。编码器测量角度或速度，IMU由加速度计和陀螺仪组成但存在漂移。测距传感器包括超声波、激光雷达和RGB-D相机。机器人视觉以相机为核心，针孔模型描述三维点到图像点的透视投影，相机标定用于求内参、外参和畸变参数。双目视觉利用视差恢复深度，核心公式为 `Z = bf/d`，立体匹配通过对极几何约束降低搜索复杂度。
