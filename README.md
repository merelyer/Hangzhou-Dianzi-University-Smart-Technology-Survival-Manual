## 这是什么

这里整理的是杭州电子科技大学智能科学与技术相关的本科课程资料，覆盖基础课、算法课、智能系统课、课程实践和项目资料。

你可以把它当成三样东西：

- 一份复习补给包：课件、往年题、复习文档、整理笔记。
- 一张课程导航图：不知道先看什么时，至少有个入口。
- 一个少走弯路的资料库：把散落在不同文件夹里的内容集中起来，方便检索和继承。

## 怎么用比较舒服

1. 先按课程名进文件夹，不要一上来全局乱翻。
2. 复习优先级可以按“复习文档 -> 往年题 -> 课件 -> 原始资料”走。
3. 实验和项目资料先看说明、报告和目录结构，再运行代码。
4. 看到别人的作业和报告，可以学习思路，但不要直接照搬。
5. 如果资料很多，先用 GitHub 搜索文件名或关键词，比肉眼翻目录省命。

## 关于大文件

这个仓库已经使用 Git LFS 管理大文件。PDF、PPT、Word、图片、压缩包、模型文件等内容会通过 LFS 存储。

如果你只是在线浏览 GitHub，正常点文件即可。  
如果你要完整克隆到本地，建议先安装 Git LFS：

```powershell
git lfs install
git clone https://github.com/merelyer/-Hangzhou-Dianzi-University-Smart-Technology-Survival-Manual.git
```

如果你已经克隆过，但发现大文件像“指针文件”，可以在仓库目录执行：

```powershell
git lfs pull
```

## 贡献方式

欢迎继续补资料，但建议遵守几个小原则：

- 文件名尽量写清楚课程、章节、年份或用途。
- 能整理成 Markdown 的笔记，尽量别只丢截图。
- 大文件继续走 Git LFS。
- 不要上传 API Key、Token、密码、`.env`、个人账号信息等敏感内容。
- 不确定能不能公开的内容，先不要传。
